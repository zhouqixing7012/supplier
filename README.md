# 供应商协同门户安全升级原型

React + Vite 可点击原型，基于当前供应商协同门户登录页、修改密码页视觉样式制作。

## 原型场景

- 登录页：保留账号、密码、图形验证码，登录后进入邮箱验证。
- 邮箱验证：验证可信注册邮箱后继续。
- 首次安全改密：本次安全事件后进行一次性密码升级，不再使用 60 天周期改密。
- 历史供应商：没有可信注册邮箱时禁止自行绑定邮箱，提示由搜狐邀请人重新邀请注册。
- 忘记密码：只允许通过已认证注册邮箱修改密码。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
