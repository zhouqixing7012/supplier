# 供应商协同门户安全升级原型

React + Vite 可点击原型，基于当前供应商协同门户登录页、修改密码页视觉样式制作。

## 原型场景

- 登录页：保留账号、密码、图形验证码，并增加评审快捷入口。
- 无邮箱处理：历史数据无邮箱时，提示联系内部人员，由产品、研发通过数据变更补录邮箱，并同步 EBS、主数据、PR。
- 60天改密：已有邮箱但密码超过 60 天未更新时，维持现有修改密码交互；修改成功后取消 60 天限制。
- 邮箱验证：已有邮箱且密码已完成升级时，登录后输入注册邮箱和邮箱验证码，校验成功后登录。
- 主动修改密码：继续通过注册邮箱验证码修改密码。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
