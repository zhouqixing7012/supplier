# PR付款跳转供应商详情

## 一、需求背景

PR系统付款功能重构计划于2027年1月27日上线。付款人员需要从PR系统进入供应商详情，核对供应商资料及相关记录。

## 二、需求详情

### 跳转方式及页面范围

PR系统通过供应商VENDORID拼接详情页URL。用户打开URL后，供应商系统校验登录状态，根据VENDORID定位供应商，并按查看规则打开现有供应商管理平台详情页。

有查看权限的用户可查看注册信息及八个页签，包括供应商信息、联系人信息、银行信息、权限信息、财务OU、黑名单操作记录、审批记录、合作信息及评分。页签内容和字段展示方式使用现有供应商详情页的定义。

### 查看规则

| 供应商范围 | 可查看人员 |
| --- | --- |
| 状态为【已审批】或【变更中】的个人撰稿人供应商 | 邀请人本人 |
| 状态为【已审批】或【变更中】的其他供应商 | 所有已登录用户 |

### 访问结果

| 访问情况 | 返回结果 |
| --- | --- |
| 未登录或登录已失效 | 进入SSO登录页。登录完成后返回原详情链接，重新校验供应商状态和查看权限。 |
| VENDORID缺失、无效、查不到供应商，或定位到其他状态的供应商 | 提示“未找到该供应商”，引导用户返回PR系统核对供应商。 |
| 供应商处于可查看状态，且用户符合查看规则 | 打开该供应商的现有详情页。 |
| 供应商处于可查看状态，但当前用户无查看权限 | 提示“您无权限查看该供应商详情”。 |
