# PR付款跳转供应商详情

## 一、需求背景

PR系统付款功能重构计划于2027年1月27日上线。付款人员需要从PR系统进入供应商详情，核对供应商资料及相关记录。

## 二、需求详情

### 跳转方式及页面范围

PR系统通过供应商VENDORID拼接详情页URL。用户打开URL后，供应商系统校验登录和详情查看权限，根据VENDORID定位供应商并打开现有供应商管理平台详情页。

有查看权限的用户可查看注册信息及八个页签，包括供应商信息、联系人信息、银行信息、权限信息、财务OU、黑名单操作记录、审批记录、合作信息及评分。页签内容和字段展示方式使用现有供应商详情页的定义。

### 访问结果

| 访问情况 | 返回结果 |
| --- | --- |
| 已登录、有详情查看权限，且VENDORID定位成功 | 打开该供应商的现有详情页。 |
| 未登录或登录已失效 | 返回未登录结果，提示“请登录后查看供应商详情”。 |
| 已登录但无详情查看权限 | 返回无权限结果，提示“您无权限查看该供应商详情”。 |

## 三、当前尚未定义

| 待确认事项 | 建议及影响 |
| --- | --- |
| PR入口适用的账号和供应商数据范围 | 建议由供应商系统按现有详情查看权限校验，具体账号和数据范围需确认。 |
| 未登录后的去向 | 建议进入供应商系统登录页，登录完成后返回原详情链接并重新校验查看权限。 |
| 有查看权限时，VENDORID缺失、无效或查不到供应商 | 建议提示“未找到该供应商”，让用户回到PR系统核对供应商。 |
