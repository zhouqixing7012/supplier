# PR付款跳转供应商详情

## 一、需求背景

PR系统付款功能重构计划于2027年1月27日上线。付款人员需要从PR系统进入供应商详情，核对供应商资料及相关记录。

## 二、需求详情

### 跳转方式及页面范围

PR系统通过供应商VENDORID拼接详情页URL。用户打开URL后，供应商系统校验登录和查看权限，根据VENDORID定位供应商并打开现有供应商管理平台详情页。PR入口的可查看供应商状态为【已审批】和【变更中】。

有查看权限的用户可查看注册信息及八个页签，包括供应商信息、联系人信息、银行信息、权限信息、财务OU、黑名单操作记录、审批记录、合作信息及评分。页签内容和字段展示方式使用现有供应商详情页的定义。

### 访问结果

| 访问情况 | 返回结果 |
| --- | --- |
| 已登录、有查看权限，且VENDORID定位到可查看的供应商 | 打开该供应商的现有详情页。 |
| 未登录或登录已失效 | 进入SSO登录页，登录完成后返回原详情链接并重新校验查看权限。 |
| 已登录但无查看权限 | 返回无权限结果，提示“您无权限查看该供应商详情”。 |
| 有查看权限，VENDORID缺失、无效或查不到供应商 | 提示“未找到该供应商”，引导用户返回PR系统核对供应商。 |

## 三、当前尚未定义

| 待确认事项 | 建议及影响 |
| --- | --- |
| PR入口是否按供应商逐家校验数据权限 | 建议供应商系统校验用户的PR付款详情查看权限和供应商状态。若所有有该权限的用户均可查看全部已审批及变更中的供应商，可共用这一查看范围。若PR付款按用户限制可选供应商，详情入口需校验同一数据范围。 |
| VENDORID定位到其他状态的供应商 | 建议按“未找到该供应商”处理，引导用户返回PR系统核对。 |
