# 移动端 PRD 评审核对记录

当前业务规则及待确认问题统一维护在 [供应商移动端 PRD](supplier-mobile-prd.md)。第5章集中列出问题、涉及功能和建议；建议须经业务确认后才能回填为正式规则。本文件保留技术核对与历史修订记录。

## 当前技术核对

| 核对事项 | 对应业务问题 | 需取得的证据 |
| --- | --- | --- |
| 删除、导出入口及执行权限 | PRD Q02、Q15 | 正式角色配置及各入口授权结果 |
| 批量删除、邀请链接与账号会话 | PRD Q03a、Q03b | 各可删状态的接口结果及会话验证 |

| 邮件验证码 | PRD Q18a、Q18b | 各场景的有效期、重发配置及验证结果 |

上述证据尚待核对，原型表现不能替代业务决定。
