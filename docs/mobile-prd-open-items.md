# 移动端 PRD 评审核对记录

当前业务规则及待确认问题统一维护在 [供应商移动端 PRD](supplier-mobile-prd.md)。第5章集中列出问题、涉及功能和建议；建议须经业务确认后才能回填为正式规则。本文件保留技术核对与历史修订记录。

## 代注册转邀请现状与目标（2026-11-13）

用户核对的旧代码先调用删除接口，清空供应商编码后再创建新邀请，两个请求间没有恢复逻辑；删除成功后即使新建失败，原草稿也已作废。第一步作废基本资料、联系人、银行、证照及资质附件引用、财务 OU、业务权限。正常代注册草稿没有账号删除动作，源码也未物理删除附件原文件。新邀请和链接先创建，再提交邮件任务，因此邮件任务报错时可能已有新记录和链接。

以上为实现现状，不作为目标规则。用户确认的失败保留要求维护在PRD 4.2.2：原草稿作废时点后移。后端需处理新记录已生成而发送任务失败后的重试，避免重复邀请；本轮仅更新文档，未改真实服务。

Q05、Q06、Q07a、Q07b、Q08、Q09已回填；Q04仅保留经营优势及资质信息的展示范围待确认。

## 用户核对结果补充（2026-11-13）

本节记录用户提供的实现核对结果，尚未由本次会话独立联调验证。业务权限、状态及展示结果已回填PRD 4.1、4.8，原Q01、Q02、Q03a、Q03b、Q15、Q24a、Q24b关闭。

- 供应商查询的批量删除流程不主动清理邀请链接缓存。正常受邀注册时已经清理缓存，批删账号后打开旧链接会提示失效；若缓存仍有残留，本次批删也不会清除。该异常边界保留，不将批量删除描述成主动使全部旧链接失效。
- 账号删除后，已有令牌不主动撤销，用户服务鉴权仅校验令牌，令牌自然过期前仍可通过该层鉴权。默认有效期自签发起24小时，并非自删除起重新计时。
- 账号删除后禁止变更和提交是已确认业务限制。仅令牌鉴权通过不能证明该限制已实现，业务操作拦截仍需联调验证。
