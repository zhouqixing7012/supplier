# 移动端 PRD 评审核对记录

当前业务需求见 [供应商移动端 PRD](supplier-mobile-prd.md)。以下事项需要核对正式配置或接口；尚未取得结果，不能作为已确认的验收规则。

| 需核对的规则 | 涉及页面或操作 | 核对重点 |
| --- | --- | --- |
| 两个列表的删除按钮分别对哪些角色显示，单条和批量操作各调用哪一删除能力？ | 两个列表的单条、批量删除 | 核对入口配置与操作权限 |
| 批量删除注册驳回记录时，旧邀请链接是否失效？账号删除后，已登录会话是否失效？ | 删除供应商 | 分别核对批量操作和会话处理 |
| 已停用的企业类别、机构类型、是否上市、是否分支机构，是否仍由审批或下游业务读取历史值？ | 企业资料、审批及下游业务 | 核对历史字段的读取范围 |
| 0.5–5 星按什么规则换算为各评分项的整数分？ | 我的评分、供应商详情评分 | 核对评分提交值，确保两个入口的评价得分一致 |
| 管理员和内审分别可使用哪些导出入口？ | 供应商查询、我的邀请导出 | 核对角色的入口配置，按 PRD 4.8 确定各入口的导出字段 |
| 登录邮件验证码有效期及服务端重发间隔是多少？换绑邮箱验证码采用哪些参数？ | 门户登录、邮箱换绑 | 核对各流程的有效期与服务端重发规则 |
| 无单据结束时间的价税拆分订单，使用结束日期筛选时取哪个业务日期？ | 价税拆分查询 | 建议由采购业务确认日期字段，避免缺失结束时间的记录被误排除 |
| 价税拆分是否允许负数、税率是否有限定范围、发票尾差及整单总额如何校验？ | 价税拆分提交 | 按采购端实际校验核对整单提交条件 |

## 本轮纠正

- 我的评分移除业务线联系人、所属部门查询条件；两项来自已隐藏的供应商评分菜单，结果展示字段保留。
- 管理平台三个菜单直接平铺，移除菜单目录下拉。
- 注册业务审批首节点规则集中到 PRD 4.13；各功能校验移回对应功能。
- 删除权限未取得正式角色配置，撤去正文中仅管理员可删的推断。
- 补回权限待删除、取消评分恢复原值、评分历史空值展示，以及国外邀请联系人手机的适用规则。

## 验证边界

本轮核对当前 PRD、历史优化需求、用户确认结论、现代码核对记录及移动原型。页面展示和演示交互不能证明正式接口、角色权限或跨系统结果已实现。原型与正式规则的已知差异须分别记录，不能改写 PRD 来迁就演示代码。
