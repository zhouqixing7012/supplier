# PR付款按供应商名称查询供应商基本信息及银行账户

## 一、需求背景

PR系统付款功能重构计划于2027年1月27日上线。付款环节已取得供应商名称时，通过一次查询获取供应商基本信息和银行账户。

## 二、需求详情

| 项目 | 规则 |
| --- | --- |
| 查询入参 | 供应商名称，必填。 |
| 可查询范围 | 供应商状态和银行账户范围按[可查询范围](pr-payment-supplier-bank-search-prd.md#可查询范围)执行。 |
| 查询结果 | 在一次接口响应中返回符合条件的供应商及其已审批生效的银行账户。同一供应商有多个已审批生效的银行账户时，返回全部符合条件的账户。 |
| 供应商名称缺失 | 返回校验结果。 |
| 查无供应商或匹配的供应商均处于可查询范围以外 | 返回无匹配供应商。 |

### 返回字段

| 信息分类 | 字段 |
| --- | --- |
| 供应商基本信息 | 供应商名称、供应商VENDORID |
| 银行账户信息 | 开户行名称、分行名称、账户名称、银行账号、银行国家编码、省、市 |

## 三、当前尚未定义

| 待确认事项 | 建议及影响 |
| --- | --- |
| 供应商名称的匹配方式和同名处理 | 建议按完整名称精确匹配。同一名称命中多家可查询的供应商时，建议按VENDORID区分并返回匹配结果，由PR系统识别对应供应商。该规则决定同名供应商及其账户如何返回。 |
