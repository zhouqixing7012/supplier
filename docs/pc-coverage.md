# PC 原型页面覆盖

核对范围为 feat/mobile-change-comparison 的 [现系统前端代码导出目录](../供应商前端代码) 和已确认需求。导出为低代码单页配置，包含字段、明细和页面脚本。PC 原型用 ERP 主题、Card、QueryBar、DetailGrid、PcTable 及 PcModal 实现页面。

| 模块 | 现系统导出 | 原型入口及覆盖 |
| --- | --- | --- |
| 供应商查询及详情 | 供应商列表-详情 | 管理平台 → 供应商查询 → 点击名称。复用九个资料页签；列表字段和菜单权限待原定义核对 |
| 邀请及邀请人变更 | 供应商-邀请注册、变更邀请人、我的邀请-详情页 | 管理平台 → 供应商查询／我的邀请。邀请、重新邀请、变更邀请人及详情可操作 |
| 代注册 | 供应商代注册、添加联系人、添加联系人 (1)、添加银行 | 供应商查询 → 代注册。四类表单，按类型显示适用步骤；资质、联系人、银行、预览及会话提交 |
| 快速创建及分配权限 | 快速创建供应商、添加权限 | 供应商查询 → 快速创建供应商；名称详情 → 分配权限。付款公司、业务实体和部门使用演示候选 |
| 修改全部信息 | 修改全部信息、修改全部信息 (1) | 我的邀请 → 变更 → 修改全部信息。两份导出内容相同。资料修改后预览，提交生成与有效资料独立的待审批快照 |
| 银行维护与审批查看 | 添加银行、修改银行信息审批 | 供应商详情 → 银行信息／审批记录。银行编辑、暂存及提交沿用现有原型；单独审批导出标注备用，现行办理节点待补 |
| 门户认证与资料 | 协同门户登录页、协同门户信息管理、协同门户信息填写 | 从 PC 门户登录进入资料查看、分步修改及待审批预览；支持演示改密及注册邮箱修改。邀请链接校验、首次注册入口及正式审批待核对 |
| 报价与价税拆分 | 协同门户-采购报价详情、采购报价详情-已处理、价税拆分同步详情页、价税拆分同步详情页 (1) | 门户 → 采购报价管理／采购价税拆分。待处理、已处理列表和详情；行内编辑、价税计算、报价多附件及演示提交。列表、筛选及访问权限待现系统配置确认 |
| 差旅账单 | 差旅账单录入 | 门户 → 差旅账单录入。四类附件独立多选、原页透传，规则以[差旅 PRD](portal-verification-travel-bill-prd.md)为准。下载与实际上传依赖宿主服务 |

## 仍需现系统资料

1. **PC 菜单、角色权限和列表配置**。管理端与门户各角色的菜单截图或导出；供应商查询、我的邀请、采购报价和价税拆分的待处理／已处理列表定义。请标明我的评分、供应商评分、评分查询、银行信息申请是否也有 PC 入口。
2. **现行业务审批**。供应商注册及资料变更的审批待办、详情、审批记录和节点动作；付款公司选择器的可选范围、显示字段与回填规则。备用银行审批导出不足以确认现行路径。
3. **首次邀请注册与服务联调**。邀请链接参数及首次注册入口的脱敏示例，付款公司、业务实体及部门字典，差旅账单模板和四类服务回执示例。页面走查可先用演示数据，正式联调使用真实服务契约。

原型内的本地演示记录不表示已完成正式认证、审批、邮件发送或文件上传。差旅未注入宿主上传服务时显示未接入。
