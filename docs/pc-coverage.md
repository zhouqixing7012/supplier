# PC 原型页面覆盖

核对范围为 feat/mobile-change-comparison 的 [现系统前端代码导出目录](../供应商前端代码)、2026-11-11 补充的两端菜单及审批页面截图，以及已确认需求。导出为低代码单页配置，包含字段、明细和页面脚本。PC 原型用 ERP 主题、Card、QueryBar、DetailGrid、PcTable 及 PcModal 实现页面。

| 模块 | 现系统导出 | 原型入口及覆盖 |
| --- | --- | --- |
| 供应商查询及详情 | 供应商列表-详情 | 管理平台 → 供应商查询 → 点击名称。复用九个资料页签；供应商查询的可见字段已与截图核对，菜单授权待按角色核对 |
| 邀请及邀请人变更 | 供应商-邀请注册、变更邀请人、我的邀请-详情页 | 管理平台 → 供应商查询／我的邀请。邀请、重新邀请、变更邀请人及详情可操作 |
| 代注册 | 供应商代注册、添加联系人、添加联系人 (1)、添加银行 | 供应商查询 → 代注册。四类表单，按类型显示适用步骤；资质、联系人、银行、预览及会话提交 |
| 快速创建及分配权限 | 快速创建供应商、添加权限 | 供应商管理 → 快速创建供应商（也可从供应商查询打开）；名称详情 → 分配权限。付款公司、业务实体和部门使用演示候选 |
| 修改全部信息 | 修改全部信息、修改全部信息 (1) | 我的邀请 → 变更 → 修改全部信息。两份导出内容相同。资料修改后预览，提交生成与有效资料独立的待审批快照 |
| 银行维护与审批查看 | 添加银行、修改银行信息审批 | 供应商详情 → 银行信息／审批记录。银行编辑、暂存及提交沿用现有原型；银行变更提交可从待审批任务打开，查看变更对比；在用银行变更节点待核对 |
| 门户认证与资料 | 协同门户登录页、协同门户信息管理、协同门户信息填写 | 从原有 PC 门户登录及安全验证页面进入 ERP 工作区，支持资料查看、分步修改及待审批预览；顶部账户菜单支持演示改密及注册邮箱修改。邀请链接校验、首次注册入口及正式审批待核对 |
| 报价与价税拆分 | 协同门户-采购报价详情、采购报价详情-已处理、价税拆分同步详情页、价税拆分同步详情页 (1) | 门户 → 采购报价管理／采购价税拆分 → 对应待处理、已处理子菜单。列表和详情支持行内编辑、价税计算、报价多附件及演示提交。列表、筛选及访问权限待现系统配置确认 |
| 差旅账单 | 差旅账单录入 | 门户 → 差旅账单录入。四类附件独立多选、原页透传，规则以[差旅 PRD](portal-verification-travel-bill-prd.md)为准。下载与实际上传依赖宿主服务 |
| 审批任务 | 待审批任务、已审批任务及注册业务审批截图 | 管理平台 → 审批任务管理 → 待审批任务／已审批任务。注册审批包含供应商、资质、联系人、银行、权限、归属部门、付款公司、流程、历史及意见。支持演示同意、驳回和办理后回查；资料及银行变更在待办中显示前后对比 |
| 评分 | 管理平台菜单截图；现有评分规则 | 我的评分、供应商评分及供应商运维-评分查询。演示评分录入、查看、修改、筛选及导出；批量发起服务待接入 |

## 仍需现系统资料

1. **PC 角色及列表配置**。按角色的菜单可见范围，我的邀请、待审批和已审批任务、评分、黑名单、银行申请、报价及价税拆分列表的字段和筛选条件。
2. **审批节点、选择器及动作**。付款公司选择器截图或配置，领导、财务及资料变更节点的可编辑字段，以及加签、延期的操作弹窗和处理规则。当前注册业务审批用演示付款公司候选，演示办理结果只更新当前审批任务。
3. **手动同步及黑名单管理**。同步对象、触发方式及回执，黑名单拉黑及移除权限和生效条件。
4. **首次邀请注册与服务联调**。邀请链接参数及首次注册入口的脱敏示例，付款公司、业务实体及部门字典，差旅账单模板和四类服务回执示例。

原型内的本地演示记录不表示已完成正式认证、审批、邮件发送或文件上传。差旅未注入宿主上传服务时显示未接入。
