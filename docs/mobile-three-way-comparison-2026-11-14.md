# 供应商移动端三方比对报告

2026-11-14 · 共 90 项差异及逐项修改建议

正式 PRD 已覆盖移动端入驻、供应商管理、协同门户和采购差旅。原型主路径大多可进入，办理条件和提交结果仍有差异。建议先按正式 PRD 修正重新邀请、删除与脱敏、邀请人交接、银行账户和权限暂存，再补齐审批、评分及门户状态。说明书需要单列新版移动端操作，保留 PC 与历史版的适用范围。

| 优先处理 | 主要差异 | 建议 |
| --- | --- | --- |
| 入驻及交接 | 邀请中不能重邀；注册驳回可误重邀；单条交接仍模拟旧审批 | 统一状态、记录归属及提交条件，演示重邀换链接和交接后立即移交 |
| 删除及隐私 | 两个列表暴露多余删除入口；导出可跳过确认，个人证件原值可能输出 | 按角色和来源列表限制删除；两处导出都经过确认，统一脱敏 |
| 银行及权限 | 开户证明仅企业强制，账户规则跨入口不一致，权限暂存离开后丢失 | 复用账户校验和记录级暂存，区分已生效与本次新增 |
| 评分及审批 | 评分保存后得分为空，汇总未更新；审批历史单号静态、缺少实际单据关联 | 补计算和原记录更新，关联对应审批单，覆盖通过、驳回和重提 |
| 门户及外部业务 | 登录统一到工作台；差旅未根据权限开放，仍允许一次多选 | 分状态登录，按账号隔离数据；差旅按权限开放、一次一份，采购与差旅按回执处理 |

## 比对范围

- 原型以 [`feat/mobile-change-comparison` 的 `10ae64f`](https://github.com/zhouqixing7012/supplier/commit/10ae64f9a8a7310641d42e5e088994a72fc6e60f) 为准。核查普通入口、详情直达、表单校验和会话结果，并查看了 47 张[原系统移动端截图索引](https://github.com/zhouqixing7012/supplier/blob/10ae64f9a8a7310641d42e5e088994a72fc6e60f/docs/mobile-screenshot-coverage.md)。原截图里的历史入口和按钮用于追溯。
- 说明书为 2026-08-25 版《供应商系统说明书（自用版）》，核对正文、17 张表、39 张嵌图及 27 条 Word 批注。截图多为 PC，手机端范围以对应文字为准。旧批注作为追溯材料。 [系统使用说明书](https://docs.google.com/document/d/1tukuf4sbt3J0VwOGT7AGNFsPjRJsMMhj/edit)
- PRD 以指定分支的[《供应商移动端 PRD》](https://github.com/zhouqixing7012/supplier/blob/10ae64f9a8a7310641d42e5e088994a72fc6e60f/docs/supplier-mobile-prd.md)为主。也核对了此前交付的[同名 PRD v9](https://chatgpt.com/library?file_id=libfile_3ffec566787881918de2edf802b711f1&account_id=personal)及仓库历史优化稿。涉及业务口径变动时，差异表注明版本。

覆盖管理平台的查询、邀请、详情、删除、导出、评分、银行及权限维护、交接，以及四类供应商登记、注册审批、门户账户、资料变更、采购报价、价税拆分和差旅上传。财务 OU、黑名单及审批任务中心仅核对移动端查看、办理和外部入口的范围。

表内源码链接固定到本次比对提交。原型的会话演示只用于检验页面和操作结果，邮件、OCR、人员银行目录、审批及采购差旅接口的真实结果需联调确认。
