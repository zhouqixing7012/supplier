# 移动端原型工程说明

站点根地址与 `#/mobile` 打开移动端管理平台的「供应商查询」。一级菜单的原型导航提供「协同门户移动端」，进入 `#/mobile/portal` 登录。截图目录：`#/mobile/scenes`。单张状态：`#/mobile/shot/截图时间`，例如 `#/mobile/shot/194652`。

## 操作权限同步

- 普通原型及导图【供应商查询】默认以管理员身份展示。导图【普通员工 · 供应商查询】单独演示员工视角，入口为 `#/mobile/query?map=1&role=employee`。导图【管理员 · 批量删除演示】直接进入批量勾选。角色在各自原型会话中保留，正式系统依据登录身份提供权限。
- 【我的评分】的已评分列表提供「评分明细演示」样例，导图的【评分详情】入口也打开该样例。
- 列表入口与提交条件按[现行PRD](supplier-mobile-prd.md)执行。我的邀请批量工具条仅提供变更邀请人；历史补账号仅通过导图独立演示路径访问。
- PRD后半部已重新编号：评分4.8、账户4.9、采购4.10、差旅4.11、审批4.12；历史核对记录中的旧章节号保留追溯。

## 移动筛选、办理步骤与输入规则（2026-11-16）

供应商筛选复用 DateRange，普通办理页面复用横向 Steps，我的评分复用 CountTabs。营业执照复用 UploadField 的证照样式，点击上传框后选择本机文件或拍照。组件库提供可操作示例。批量入口与查询条数同行，卡片使用“查看详情”“修改草稿”等明确文案。

账号、邮箱的空白处理见 [现行PRD第3.3节](supplier-mobile-prd.md#33-账号和邮箱的空格处理)。前端原型对受邀注册及修改密码保留格式与确认校验，提交和比对使用用户输入的密码原值。

## 采购明细本地暂存

协同门户以同一账号在本浏览器重新登录后，可恢复报价或价税拆分已单条保存的明细。原型通过浏览器 IndexedDB 按账号、任务类型、单据及明细行保存，文件内容随报价明细一并保存。放弃未保存修改时保留已保存明细，整单提交成功后清除该单据的暂存。直接打开演示页面时使用当前会话数据。跨设备使用正式采购暂存服务。

移动端上传空态采用并排的「选择文件／照片」和「拍照」入口；仅支持本地文件的上传控件直接展示文件选择按钮。

## PC 现状补齐项的预览与联调（2026-11-15）

- 历史账号演示从原型导图独立的【历史补账号演示（范围外）】进入，普通业务详情不展示补账号入口。由演示员工交接后，打开详情的重新邀请入口，再打开本次演示注册链接。链接在当前原型会话内按生成起 7 天校验；重新发送、再次交接或开通账号后，旧链接失效。历史补账号的正式发链、失效和发送异常需联调。
- 企业执照上传后先调用 `window.__SUPPLIER_DOCUMENT_OCR__({ kind: 'license', file })`，取得 `supplierName` 和 `creditCode` 后自动调用宿主的天眼查适配点 `window.__SUPPLIER_ENTERPRISE_LOOKUP__({ name, creditCode })`。宿主返回匹配企业资料，并转换为表单字段。等两步成功后统一回填；结果不匹配或查询失败时保留附件和已填信息。
- 个人代注册按目录选择开户银行及分行，手工填写银行账号。银行卡照片作为开户证明附件保存。
- `window.__SUPPLIER_ATTACHMENT_DOWNLOAD__({ fileId, signal })` 由宿主授权后返回原始 `Blob`。已存附件传入 `{ fileId, name }`，当前会话新文件使用原始上传对象生成预览及下载。仅有文件名的历史样例提示原件不可用。
- 开户银行和分行采用本地目录样例，省市回填严格匹配同一银行和分行。境外目录及对应字段、正式开户证明与 EBS 数据仍需联调。
- 原型导图的【注册审批及结果邮件演示】提供四类供应商入口，按基本信息、资质、联系人及银行等实际登记分组展示本次提交资料和附件。首个业务节点选择付款公司，后续节点填写审批意见并办理。结果邮件为页面预览。
- 采购通知从演示链接进入登录验证后，只允许专用账号 `supplier-demo` 打开对应会话单据。正式工作流、邮件投递、采购链接格式和服务端单据授权需联调。
