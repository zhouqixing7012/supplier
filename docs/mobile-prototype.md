# 移动端原型工程说明

入口：`#/mobile`。截图目录：`#/mobile/scenes`。单张状态：`#/mobile/shot/截图时间`，例如 `#/mobile/shot/194652`。

## 页面实现

- 移动端使用独立 React 入口，与电脑端模块通过 Hash 切换并重载，避免样式污染。
- 所有页面、表单、弹层和列表使用真实 DOM；截图入口不使用整张图片代替可操作界面。
- `mobile-data.js` 保存截图演示样本和 47 个状态映射。原截图不作为真实供应商、员工、评分或银行数据源。
- 原型数据保存在本次页面会话内，刷新恢复演示样本。邮件、OCR、员工目录、银行目录、审批和登录均未对接真实服务。
- 新增、修改银行和权限先在当前页面暂存；提交后模拟进入变更中，详情继续读取已审批版本。
- 业务规则来源和本轮授权范围见 `mobile-prd.md`。

## 截图状态与普通路径

原截图入口保留页面索引及演示样本，当前页面统一应用修复，不再承担现状与新版对照验收；普通路径用于连续操作。

- 截图入口保留手机状态栏、Android 底栏和可关闭的截屏提示；`vConsole` 仅为截图外观，不是调试服务。
- 普通路径明确标记“演示数据”，不默认弹出截屏提示。
- 普通注册表单展示必填注册邮箱；原截图早期注册页保留原有字段，用于现状对照。
- 截图中的姓名、公司、日期、账号等仅作视觉样本。登录密码使用独立演示值，不保存说明书里的测试账号密码。
- 说明书只允许草稿删除，截图中邀请中状态的删除按钮不执行旧行为。
- 发起人为原邀请人时直接通过；原邀请人离职的审批提示按说明书展示部门领导、异常管理员路径，审批服务不在前端模拟。
- 批量变更邀请人、评分运维批量发起仍缺少完整规则，点击明确提示未执行；评分填写、详情和修改已接通。银行申请进入真实DOM表单，提交仅显示本次演示保存，不模拟申请单号或审批完成。
- 员工、分行和省市区选择仅包含截图证实的演示条目；未收录的项明确展示空状态，不自动替代。
- 样本附件预览复用提供的截图中可见的图像区域；上传的新附件可预览本地图片，未提供原件的样本不会假装可下载。
- 登录图形验证码演示值为 `cbvs` / `39qq`，邮箱验证码演示值为 `123456`，发送时提示未发送真实邮件。
- 普通原型不开放内审或管理员专属导出；管理员截图状态可导出标注为演示数据的 CSV，不导出线上数据。

## 图片素材

素材来源及生成提示记录在 `public/mobile-assets/SOURCES.md`。城市背景由参考截图还原，建筑细节不属于逐像素保证范围。插画、证照缩略图按原截图的图像区域显示。

## 验证

```bash
npm install
npm run build
npx playwright install chromium
npm run test:mobile
```

浏览器测试自行启动本地生产构建服务，覆盖 47 个截图状态、筛选、取消、提交、邀请、人员选择、导出、删除限制、验证码及不同宽度。结果和截图写入忽略目录 `test-output/mobile`。

特殊环境可通过 `PLAYWRIGHT_MODULE` 指定已安装模块入口，通过 `CHROMIUM_BIN` 指定浏览器二进制；不把本机路径写成其他环境必须具备的路径。
