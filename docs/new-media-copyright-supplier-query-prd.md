# 新媒体版权供应商统一管理及查询接口 PRD

## 1. 需求背景

此前新媒体版权业务自行维护供应商信息。后续新媒体版权供应商统一纳入供应商管理平台，由供应商管理平台维护供应商主数据及新媒体版权业务权限。新媒体版权系统通过接口查询符合业务权限的供应商，使用统一的供应商资料。

## 2. 需求范围

1. 供应商主数据统一在供应商管理平台维护。
2. 供应商管理平台新增【新媒体版权】所属权限，权限分类为【免费类】和【采购类】。权限字段、保存、重复校验及审批生效规则见[供应商移动端 PRD 4.6 分配权限](supplier-mobile-prd.md#46-分配权限)。
3. 新媒体版权系统调用供应商查询接口，按供应商名称、所属业务和业务分类查询供应商列表。

## 3. 新媒体版权权限

| 字段 | 取值 |
| --- | --- |
| 所属权限 | 新媒体版权 |
| 权限分类 | 免费类、采购类 |

供应商通过供应商管理平台分配新媒体版权权限。新增、修改和删除权限沿用现行权限维护流程；权限审批通过后更新正式权限，待审批或已驳回的变更不作为已生效权限提供给外部系统。

## 4. 供应商查询接口

### 4.1 接口信息

| 项目 | 内容 |
| --- | --- |
| 接口名称 | 按供应商业务查询供应商列表 |
| 调用系统 | 新媒体版权系统 |
| 接口地址 | `{SUPPLIER_URL}/api/supplier/supplierInfoBySupplierBusiness{SUPPLIER_URL_PARAM}` |
| 接口用途 | 按供应商名称、所属业务及业务分类查询供应商列表 |
| 请求方式 | 待接口双方确认 |

### 4.2 查询条件

| 查询字段 | 含义 | 本次支持的取值 |
| --- | --- | --- |
| 供应商名称 | 按供应商名称筛选供应商 | 供应商名称 |
| 所属业务 | 对应供应商管理平台的【所属权限】 | 新媒体版权 |
| 业务分类 | 对应所选所属业务下的【权限分类】 | 免费类、采购类 |

建议参数名如下，最终参数名以双方确认的接口字段表为准：

| 中文字段 | 建议参数名 |
| --- | --- |
| 供应商名称 | supplierName |
| 所属业务 | supplierBusiness |
| 业务分类 | businessCategory |

### 4.3 查询范围与结果

1. 供应商资料以供应商管理平台当前正式生效的资料为准。
2. 查询结果须匹配供应商已生效的【新媒体版权】权限及对应业务分类。
3. 尚未审批通过的新增或修改权限不纳入查询结果；权限变更审批驳回时，继续按原正式权限查询。
4. 接口返回符合查询条件的供应商列表。无匹配供应商时的响应结构及提示方式待接口双方确认。

### 4.4 返回数据

返回字段尚未确定。建议至少包含供应商唯一标识、供应商名称、命中的所属业务和业务分类，确保新媒体版权系统能够识别供应商及其授权业务。

其他供应商资料字段按新媒体版权系统的实际使用场景确定，不在本需求中预设。

## 5. 当前尚未定义

| 编号 | 待确认问题 | 涉及内容 | 建议及影响 |
| --- | --- | --- | --- |
| Q1 | 接口请求方式、认证方式及调用方身份如何确定？ | 接口接入 | 建议采用系统间身份认证，并限定新媒体版权系统调用；具体认证方式需结合现有网关确定。 |
| Q2 | 三个查询条件的必填性、名称匹配方式及多条件组合规则是什么？ | 查询条件 | 建议供应商名称支持模糊查询；多个已传条件按交集筛选。最终规则会影响查询结果范围。 |
| Q3 | 接口需要返回哪些供应商字段，是否需要分页及排序？ | 返回数据 | 建议至少返回供应商唯一标识、供应商名称、所属业务和业务分类；分页、排序及其他字段按新媒体版权系统页面使用方式确认。 |
| Q4 | 供应商状态、停用及黑名单记录是否需要从查询结果中排除？ | 查询范围 | 需明确可供新媒体版权业务使用的供应商范围，避免返回不可继续合作的供应商。 |
| Q5 | 原新媒体版权系统中的供应商是否需要批量迁移至供应商管理平台？迁移哪些资料，如何匹配已有供应商并处理重复记录？ | 历史供应商纳入 | 需确认迁移范围、数据来源、匹配依据及重复数据处理方式，避免重复创建供应商主数据。 |
| Q6 | 无匹配数据、参数错误及系统异常时，接口采用什么响应结构和错误码？ | 接口响应 | 需与现有接口规范统一，便于调用方区分无数据、参数错误和服务异常。 |
