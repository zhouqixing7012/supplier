# 供应商移动端原型

目标：根据提供的移动端现状截图，复刻可点击的移动端原型，支持逐张查看和连续操作。

## 已确认范围

- 覆盖全部 47 张截图。页面、弹层、筛选、空状态、批量选择、分步填写、滚动位置分别保留对应入口。
- 覆盖供应商查询、我的邀请、详情、审批记录、修改银行、分配权限、变更邀请人、邀请注册、代注册、评分相关页面、银行信息申请及移动协同门户登录。
- 外观以截图为依据；业务规则以《供应商系统说明书（自用版）》为依据。
- 截图与说明书存在冲突时，不从旧页面行为推导新的业务规则。例如，删除仅对符合说明书条件的草稿开放。
- 截图存在而说明书规则不完整的功能，复刻已展示的页面与交互；涉及未确认的业务结果时，说明限制，不新增业务规则。

## 规则来源

供应商状态、删除权限、银行基本账户、邀请人变更审批、个人信息保护及注册校验的业务依据统一维护在原说明书中：

[供应商系统说明书（自用版）](https://drive.google.com/file/d/1tukuf4sbt3J0VwOGT7AGNFsPjRJsMMhj)

当前项目已确认的新增注册邮箱要求维护在 `PRODUCT.md`，本原型普通填写路径遵循该要求。截图入口保留原截图字段以供现状对照，差异和演示限制见 `mobile-prototype.md`。

## 完成标准

- 47 张截图均有明确对应入口，逐张覆盖情况见 `mobile-screenshot-coverage.md`。
- 可从列表进入详情、银行、权限及邀请人页面；可取消、修改、验证并提交已确认流程。
- 邀请注册及代注册支持必填校验、分步填写和结果状态展示。
- 修改银行和权限提交后，演示供应商进入变更中；详情保留变更前版本。
- 登录支持图形验证码、邮箱验证码及错误提示；演示结果与真实业务服务明确区分。
- 构建与浏览器验证的实际结果记录在项目上下文及工程说明中。
