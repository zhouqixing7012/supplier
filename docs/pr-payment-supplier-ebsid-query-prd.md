# PR付款按EBSID查询供应商及银行账户

## 一、需求背景

PR系统付款功能重构计划于2027年1月27日上线。付款环节已取得供应商的EBSID时，需要通过一次查询取得供应商基本信息及银行账户信息。

## 二、需求详情

| 项目 | 规则 |
| --- | --- |
| 查询入参 | EBSID |
| 匹配方式 | 按EBSID精确查询。一个EBSID最多对应一个供应商。 |
| 可查询范围 | 供应商状态和银行账户范围按[可查询范围](pr-payment-supplier-bank-search-prd.md#可查询范围)执行。 |
| 查询结果 | 在同一次接口响应中返回该供应商的基本信息及其符合范围的银行账户信息。 |

## 三、当前尚未定义

| 待确认事项 | 建议及影响 |
| --- | --- |
| 供应商基本信息及银行账户的返回字段 | 基本信息建议先明确供应商名称、供应商VENDORID及是否回传EBSID。银行账户字段建议参考[按名称和银行账号查询的返回字段](pr-payment-supplier-bank-search-prd.md#返回字段)。完整字段清单由PR系统按付款场景确认。 |
| 同一供应商有多条或没有已审批银行账户 | 建议有多条时返回全部符合范围的银行账户，没有时返回供应商基本信息和空账户清单。该规则影响PR系统是否还能核对供应商。 |
| EBSID缺失、查无供应商，或供应商状态不在可查询范围内 | 建议EBSID缺失时返回校验结果，查无供应商或供应商状态不在范围内时返回无匹配供应商。该规则影响PR系统如何提示付款人员。 |
