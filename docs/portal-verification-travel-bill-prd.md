# 供应商协同门户验证码及差旅账单上传

## 一、协同门户登录邮箱验证码固定值支持

背景：

协同门户此前已支持测试环境图形验证码固定为 1234。后续登录流程新增邮箱验证码，自动化测试仍需读取邮件获取验证码，影响登录流程自动化执行，现需补充邮箱验证码固定值支持。

需求详情：

1. 测试环境开启固定验证码开关后，图形验证码及登录邮箱验证码均输入 1234 通过校验；图形验证码仍随机显示，输入其他内容或未填写时校验不通过。
2. 邮箱验证码仍需点击获取并实际发送邮件，发送成功且在有效期内才可使用 1234 校验；未获取、发送失败或已过期时校验不通过。
3. 关闭固定验证码开关后，按实际生成的验证码校验；生产环境默认不开启固定验证码模式。
4. 固定值仅用于验证码校验，账号密码、账号状态等其他登录条件仍需正常校验。

## 二、差旅账单上传

背景：

供应商需要在协同门户内上传火车、酒店、飞机和租车账单。账单文件由供应商系统接收后透传至差旅系统对应的服务入口处理，供应商无需跳转到差旅系统页面。

需求详情：

1. 差旅账单分为火车账单、酒店账单、飞机账单和租车账单四类。页面固定展示四类上传入口，四类均可上传，不按供应商权限隐藏。
2. 每类账单独立提供“上传附件”按钮。点击按钮后，在当前页面选择该类账单附件；文件选择完成后提交至对应的差旅服务入口。
3. 不设置账期。供应商端不限制附件数量、文件格式及大小；一次可选择多个附件并提交至对应差旅服务。
4. 上传期间显示加载状态，并禁用当前类型的上传按钮。差旅服务确认成功后提示上传成功；接口返回失败时显示失败原因并允许重新上传。
5. 上传请求等待时间为180秒。超过180秒未收到响应时提示上传超时，不将超时直接判定为差旅服务处理失败。
6. 供应商系统仅负责接收附件并透传至差旅服务，不在供应商端保存账单文件，不跳转至差旅系统页面。
7. 差旅账单页面底部不增加“返回工作台”按钮。

此前“账期”“仅支持xls/xlsx”“单附件”及“保存草稿”等方案不再作为当前需求。
