# 供应商协同门户验证码及差旅账单入口

## 一、协同门户登录邮箱验证码固定值支持

背景：

协同门户此前已支持测试环境图形验证码固定为 1234。后续登录流程新增邮箱验证码，自动化测试仍需读取邮件获取验证码，影响登录流程自动化执行，现需补充邮箱验证码固定值支持。

需求详情：

1. 测试环境开启固定验证码开关后，图形验证码及登录邮箱验证码均输入 1234 通过校验；图形验证码仍随机显示，输入其他内容或未填写时校验不通过。
2. 邮箱验证码仍需点击获取并实际发送邮件，发送成功且在有效期内才可使用 1234 校验；未获取、发送失败或已过期时校验不通过。
3. 关闭固定验证码开关后，按实际生成的验证码校验；生产环境默认不开启固定验证码模式。
4. 固定值仅用于验证码校验，账号密码、账号状态等其他登录条件仍需正常校验。

## 二、差旅账单入口

背景：

供应商协同门户需要提供不同类型差旅账单的上传入口。实际账单上传由差旅系统处理，供应商协同门户仅负责展示有权限的入口并进入差旅系统对应页面。

需求详情：

1. 差旅账单分为火车账单、酒店账单、飞机账单和租车账单四种类型；每种类型对应差旅系统中的独立上传入口。
2. 当前供应商可使用的账单类型由差旅系统权限控制。供应商协同门户根据差旅系统返回的权限展示对应入口，不自行根据供应商类型推断或补充权限；未授权的类型不展示。
3. 点击账单类型入口后，进入差旅系统中该类型对应的上传入口，由差旅系统完成文件选择、上传和结果反馈。
4. 供应商协同门户不设置账期，不限制附件数量、格式或大小，不保存账单附件，不处理上传状态或上传结果。相关校验及处理规则由差旅系统负责。

历史方案（2026-10-15）曾按单文件上传和180秒超时设计；本次最新确认以差旅系统入口跳转方案为准，历史上传规则不再作为当前要求。
