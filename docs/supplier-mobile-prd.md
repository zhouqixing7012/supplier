# 供应商移动端 PRD

## 1. 使用范围

内部员工可在移动端办理供应商业务，外部供应商可完成入驻及后续协同。

| 使用端 | 本次范围 |
| --- | --- |
| 供应商管理平台 | 供应商查询、我的邀请、邀请注册、代注册、供应商详情、审批记录查看、修改全部信息、修改银行、分配权限、变更邀请人、我的评分 |
| 供应商协同门户 | 受邀账号注册及资料登记、登录与账户维护、供应商信息管理、采购报价、价税拆分、差旅账单上传 |

采购报价和价税拆分任务来自采购系统，上传的差旅账单由差旅系统处理。PC 专属页面改造、财务 OU 分配、黑名单办理、撰稿人新增授权及审批结束服务号通知在本次范围之外。移动端管理平台将【供应商查询】【我的邀请】【我的评分】三个菜单在同一行直接展示，点击切换。

## 2. 权限

权限分别控制菜单入口、可见数据和可执行操作。办理业务时，须同时满足对应入口权限、数据范围、操作权限及当前业务状态条件。

### 2.1 菜单权限

菜单权限控制用户可见、可进入的业务页面。

| 使用端 | 菜单或入口 | 开放范围及条件 |
| --- | --- | --- |
| 供应商管理平台 | 供应商查询、我的邀请、我的评分 | 全体正编员工 |
| 协同门户 | 工作台及供应商信息管理、采购报价、价税拆分 | 已审批、变更中的供应商进入工作台，办理本账号绑定供应商的业务 |
| 协同门户 | 差旅账单录入 | 按供应商的差旅权限开放，访问及上传规则见4.11 |
| 协同门户 | 注册、注册详情、注册驳回后的资料修改 | 按供应商当前状态进入对应页面，逐状态去向见4.9.1 |
| 协同门户 | 修改密码、修改注册邮箱、退出登录 | 从账户设置进入，办理条件见4.9.3 |

### 2.2 数据权限

数据权限控制菜单内可查询、查看及办理的记录范围。

| 使用场景 | 可见数据范围 |
| --- | --- |
| 供应商查询 | 有供应商管理权限的正编员工查看普通供应商，以及获授权查看的个人撰稿人 |
| 我的邀请 | 当前归属本人的邀请注册及代注册记录，以及已交接给本人的历史供应商 |
| 我的评分 | 本人的待办及已办评分记录 |
| 受邀登记 | 有效邀请链接对应的供应商 |
| 协同门户 | 本账号绑定的供应商资料及采购业务任务 |
| 详情及附件 | 按所属供应商的数据权限开放。银行账户详情展示账户资料，开户证明在注册预览、银行维护和相关审批页面按权限查看 |

供应商列表及普通详情中的个人证件号保留前两位和后两位，中间用星号显示。证件原值仅用于授权业务。列表及详情字段缺值时统一显示“—”。

## 3. 通用规则

### 3.1 供应商状态与资料版本

| 状态 | 进入条件 | 可继续办理事项 |
| --- | --- | --- |
| 草稿 | 代注册资料已保存，尚未提交 | 在原记录继续填写，符合条件时删除、重新邀请或转为邀请注册 |
| 邀请中 | 邀请已发送，受邀人尚未完成账号注册 | 受邀人通过有效链接注册账号，邀请人可重新邀请 |
| 注册中 | 受邀人已创建账号，资料尚未正式提交 | 继续登记并提交注册资料 |
| 审批中 | 首次注册资料提交成功，或注册驳回后修改全部信息再次提交成功 | 查看审批进度，审批完成后更新注册结果 |
| 已审批 | 注册审批通过，或已生效供应商本次变更审批结束 | 按数据、状态及业务权限办理评分、资料维护、交接等操作 |
| 注册驳回 | 注册申请被驳回 | 协同门户登录后进入修改全部信息页；查看审批意见并修改，提交成功进入【审批中】；符合条件时删除 |
| 变更中 | 供应商资料、银行账户或权限变更已提交审批 | 查看本次审批。已生效资料继续供查询和下游使用，待审批资料在对应办理记录中查看 |

注册审批通过后生成或更新正式供应商资料。变更审批通过后更新正式资料；驳回时保留原正式资料和本次审批记录。资料维护的进入条件与提交条件按对应功能分别校验；修改全部信息的提交状态校验见4.4。评分和变更邀请人的条件分别见 4.8、4.7。

### 3.2 查询、选择和提交

1. 多个已应用的筛选条件同时生效。应用后更新结果数；取消筛选保留上次已应用条件。重置清空本次筛选填写，应用后刷新查询。清空搜索词保留已应用筛选。返回来源列表恢复查询、筛选和浏览位置。
2. 业务页签点击切换。常用单选点选后回填并关闭，已选值在重开时回显。供应商状态、行业、银行及分行等需要检索的选择保留搜索。人员选择点选后点击【确认】，取消保留原值。
3. 查询中显示加载状态。空结果提示调整条件，查询失败保留条件并允许重试。批量选择仅作用于当前查询结果中可选记录，查询范围变化后重新选择。
4. 单条保存校验当前明细，下一步校验当前步骤，提交校验整份资料。校验失败时定位出错字段、明细或步骤，保留其他输入。同一次提交只生成一笔业务结果；提交失败提示原因并保留本次资料。

### 3.3 账号和邮箱的空格处理

适用于登录、受邀账号注册、邀请填写、供应商资料登记及修改、联系人维护及修改注册邮箱。

| 字段 | 处理方式 | 校验及结果 |
| --- | --- | --- |
| 登录账号、注册账号 | 离开字段时自动去除首尾空白 | 使用处理后的值校验、查重、登录及保存；全部为空白时按必填校验。通过供应商名称登录时保留名称中间的空格 |
| 注册邮箱、联系人邮箱及新邮箱 | 离开字段时自动去除首尾空白 | 使用处理后的值校验邮箱格式、发送验证码及保存；邮箱中间含空白时提示格式错误 |

上述空白包括半角空格、全角空格、制表符等空白字符。登录、注册、发码和保存时再次执行同样处理与校验。

| --- | --- | --- | --- |
| 搜索关键词 | 两个列表 | 文本输入 | 供应商查询按供应商名称或当前邀请人姓名模糊匹配，任一命中即展示同一记录一次；我的邀请按供应商名称模糊匹配 |
| 供应商类型 | 两个列表 | 单选下拉：企业供应商、个人供应商、政府机构或社团、国外供应商 | 按所选类型筛选 |

#### 4.1.2 删除供应商

| 来源列表 | 操作权限与方式 | 可删除状态 |
| --- | --- | --- |
| 供应商查询 | 删除按钮仅管理员可见。进入批量模式后逐条勾选；只选一条时也按批量规则校验 | 草稿、注册驳回 |
| 我的邀请 | 对本人名下记录提供单条删除 | 草稿、邀请中、注册中、注册驳回 |

删除须同时满足可删除状态及未发生合作两个条件。批量删除提交前逐条复核；全部符合时才执行。发现不符合的记录时提示调整选择，本批记录保留。确认删除成功后，供应商资料作废，列表移除记录。两个入口的后续结果分别如下：

| 来源及记录状态 | 删除结果 |
| --- | --- |
| 供应商查询：草稿 | 仅作废供应商资料 |
| 供应商查询：注册驳回 | 作废供应商资料并删除供应商账号；正常完成受邀注册的记录，旧邀请链接再次打开时提示失效 |
| 我的邀请：草稿 | 作废供应商资料 |
| 我的邀请：邀请中 | 作废供应商资料，原邀请链接失效 |
| 我的邀请：注册中、注册驳回 | 作废供应商资料，原邀请链接及账号失效 |

打开失效链接时提示“该地址已失效，请联系邀请人重新邀请！”。

账号删除后，重新登录提示“用户不存在！”。已登录会话保留至原有效期结束，默认有效期从本次登录会话建立时起算24小时；账号删除后立即禁止变更和提交操作。

企业、政府机构或社团、国外供应商可添加、编辑和删除联系人。单条保存后回到当前联系人列表，删除须确认。读取已有联系人时保留其历史字段，正式提交时提示补齐必填资料。企业、政府机构或社团、国外供应商在联系人步骤保存和提交注册时，均至少有1名联系人。

| 字段 | 必填 | 填写规则 |
| --- | --- | --- |
| 姓名 | 是 | 文本 |
| 电话 | 是 | 文本，保留联系方式原值 |
| 邮箱 | 是 | 校验邮箱格式 |
| 部门 | 否 | 最多 50 字 |
| 职位 | 否 | 最多 50 字 |
| 微信 | 否 | 文本 |
| 备注 | 否 | 最多 400 字 |

#### 4.3.3 银行信息

银行信息支持添加、修改、删除及单条【保存此账户】。账户名称默认带入供应商名称，可修改。企业账户分为基本账户、一般账户。

| 字段 | 必填 | 填写或回填规则 |
| --- | --- | --- |
| 账户类型 | 企业必填 | 基本账户、一般账户；仅企业显示 |
| 开户银行 | 是 | 从银行目录搜索并选择正式银行名称；结果显示银行名称、国家或地区代码及名称 |
| 银行分行 | 是 | 选择开户银行后，搜索该银行的分行；结果显示分行全称、所属银行、国家或地区代码及名称、省、市 |
| 开户行所在国家／地区 | 是 | 选择开户银行立即带出，只读；已存草稿缺值时按其银行目录补齐 |
| 开户所在省 | 是 | 选择分行带出，只读；缺值时阻止保存 |
| 开户所在市 | 是 | 选择分行带出，只读；缺值时阻止保存 |
| 账户名称 | 是 | 最多 100 字 |
| 银行账号 | 是 | 去除账号中的空格后校验并保存，最多 50 字，按文本保存并保留前导零 |
| 币种 | 是 | 从可用币种选择 |
| 开户证明 | 是 | 支持PNG、JPG、GIF、JPC、BMP图片，每份最大50 MB；每条银行账户上传1份，可查看已保存的证明。个人供应商可上传银行卡照片作为开户证明 |
| 备注 | 否 | 最多 400 字 |

更换开户银行后更新国家或地区，清空分行、省、市，保留账户名称、账号、币种、证明及备注。分行使用目录正式名称，已存账户缺值时按同一银行与分行记录补齐。未找到开户银行或分行时先核对关键词和所选开户银行，目录缺失时提示联系业务对接人补充。省或市缺失时，补齐后再保存。

单条保存须填写表中必填字段。账号去除空格后为空时提示填写银行账号，缺少开户证明时提示上传，国家或地区为空时提示选择开户银行。注册提交须至少有一条有效账户。

企业账户同时执行以下校验：

| 操作 | 校验与提示 |
| --- | --- |
| 保存账户 | 第二个基本账户不能保存，提示“基本账户只能有一个” |
| 提交注册或银行变更 | 须恰好有一个有效基本账户，否则提示“企业供应商必须有且只有一个基本账户” |
| 修改已生效基本账户 | 可修改字段及账户类型。改为一般账户时，须在同一份提交中指定唯一的基本账户；改类型后原账户仍保留 |
| 删除已生效基本账户 | 保留原账户。即使在本次办理中已改为一般账户，仍提示“企业供应商基本账户不可删除” |
| 修改或删除本次新增且尚未提交的基本账户 | 可修改，也可删除；修改后保存仍按账户字段及基本账户数量校验，删除后从本次填写中移除 |

#### 4.3.4 资质信息与附件

仅企业供应商提供资质信息，整体选填，可按条新增、编辑和删除。

| 资质等级 | 否 | 最多50字 |
| 资质编号 | 否 | 最多50字 |

| 有效开始日期 | 否 | YYYY-MM-DD |
| 有效结束日期 | 否 | YYYY-MM-DD |
| 附件 | 否 | 每条最多1份，支持PNG、JPG、GIF、JPC、BMP图片，最大50 MB；新附件上传成功后替换原附件，失败时保留原附件并允许重试 |

有效开始、结束日期均填写时，结束日期须晚于开始日期；相同或早于开始日期时阻止保存并提示修正。

| 操作 | 结果 |

| 取消单条编辑 | 保留原条目和原附件 |

### 4.4 修改全部信息

**进入编辑**

本节分别说明已生效资料变更与注册驳回后的资料修改。

| 入口 | 办理条件及进入位置 | 提交成功后的返回位置 |
| --- | --- | --- |
| 管理平台“我的邀请”【修改全部信息】 | 当前邀请人名下、已审批且未拉黑；带入该供应商已生效资料 | 我的邀请 |
| 协同门户“供应商信息管理”【修改】 | 已审批、注册驳回时可进入；从基本信息、联系人信息或银行信息进入相应编辑步骤，提交时重新校验状态 | 来源供应商信息管理页面 |
| 注册驳回后登录协同门户 | 进入修改全部信息页，查看审批意见并修改资料 | 见本节提交结果 |

办理步骤及步骤条按4.3展示，前后切换保留本次整份资料。

已有独立银行待提交资料时，仍可进入【修改全部信息】。提交整份资料时重新校验供应商当前状态；处于【变更中】时阻止提交，提示当前状态并保留本次填写。

**填写与预览**

基本字段、联系人、银行及资质分别按4.3.1～4.3.4填写，保留对应供应商类型的适用条件。邀请人可同时修改注册邮箱。修改已有供应商时，按4.3.1“注册提交查重”检查名称及证件号码。

单条保存的联系人、银行账户及资质明细仍属于本次整份修改。【下一步】显示当前步骤并校验当前步骤；进入预览前校验整份资料，预览汇总本次拟提交内容。

**取消与提交**

取消、提交及审批结果按下表处理。变更审批结果适用于已生效资料变更。

| 操作或结果 | 处理 |
| --- | --- |
| 已有修改时取消或离开 | 提示“是否放弃本次全部修改？” |
| 【继续编辑】 | 保留本次全部内容 |
| 放弃修改 | 恢复进入编辑前的整份资料，包含附件、注册邮箱，以及已单条保存的新增、修改、删除 |
| 注册驳回后预览并提交 | 校验整份注册资料，通过后提交注册审批，供应商进入【审批中】；审批中详情展示本次提交资料，全部字段只读。提交后的返回页面及审批记录衔接见第5章Q27 |
| 已生效资料预览后提交 | 按本节提交条件复核状态并校验整份资料；成功后进入【变更中】并返回来源，可在审批记录查看进度及修改前后资料 |
| 提交失败 | 保留本次修改，提示原因 |
| 审批通过 | 更新正式资料；邀请人修改的注册邮箱同步更新至正式注册邮箱和账户验证邮箱 |
| 审批驳回 | 保留原正式资料和本次审批记录；再次办理从原申请入口发起新申请，见4.12 |

示例：在本次整份编辑中新增一条联系人并保存，再修改银行账户；点击【取消】并确认【放弃修改】后，两项修改均撤销，恢复进入编辑前的资料。

### 4.5 修改银行

**进入与维护账户**

供应商处于【已审批】且未拉黑，操作人符合2.3对应菜单的人员条件时，从供应商查询或我的邀请进入独立维护页。页面展示供应商名称、供应商类型及账户列表，账户字段及单条保存要求见4.3.3“银行信息”字段表，企业基本账户限制见该节“企业账户”校验表。

| 操作 | 保存后的结果 |
| --- | --- |
| 新增账户 | 保存后显示【待提交新增】 |
| 修改账户 | 保存后显示本次填写结果和【待提交修改】；恢复原值后取消修改标记 |
| 删除已生效账户 | 执行4.3.3“删除已生效基本账户”校验；允许删除时，确认前展示开户银行、账户名称及账号尾号，确认后显示【待提交删除】，保留原资料供核对 |
| 删除本次新增且尚未提交的账户 | 确认后该条退出本次变更，包含本次新增的基本账户 |

单条保存成功后返回银行维护页，定位到该账户的首个变更字段。没有字段对比时定位到账户卡片。变更字段可核对本次值和原值，其他字段显示本次值。

开户证明按普通附件查看。仅更换开户证明也属于有效变更，可以提交审批。

**离开与提交审批**

点击左上角返回图标离开，点击底部【提交审批】提交本次变更。已保存的待提交资料在退出或重新登录后仍可继续处理。

| 操作或结果 | 处理 |
| --- | --- |
| 有待提交内容时返回 | 提示“银行信息尚未提交审批，已保存内容将保留，可稍后继续处理。”用户可继续处理或确认离开 |
| 提交审批 | 存在有效变更时可提交；执行4.3.3“提交注册或银行变更”的基本账户数量校验 |
| 提交成功 | 供应商进入【变更中】，账户结束本次待提交状态 |
| 提交失败 | 保留待提交内容 |
| 审批结果 | 按4.12办理：通过后更新正式银行信息；驳回后保留原正式银行信息，再次办理时发起新申请 |

示例：在独立“修改银行”页保存一条新账户后返回，重新登录仍可继续提交该账户；4.4整份资料编辑中的【放弃修改】则撤销本次整份修改。

供应商处于【已审批】且未拉黑，操作人符合2.3对应菜单的人员条件时，从供应商记录进入独立维护页。

**填写权限**

列表按条展示所属权限、权限分类、备注。新增时填写下表字段，修改时回填当前记录。

| 字段 | 必填 | 交互与规则 |
| --- | --- | --- |
| 所属权限 | 是 | 单选；更换后清空原权限分类 |
| 权限分类 | 是 | 单选，候选范围由所属权限确定 |

| 所属权限 | 权限分类 |
| --- | --- |

### 4.7 变更邀请人

**进入交接**

供应商须已审批且未拉黑，操作人员按2.3对应菜单确定。单条从供应商记录进入，批量从我的邀请选择供应商后进入。

| 办理方式 | 展示内容 |
| --- | --- |
| 单条 | 供应商名称、供应商类型、原邀请人及其部门 |
| 批量 | 所选供应商数量及明细 |

**选择与确认**

1. 打开人员选择时提示输入姓名或工号。输入后搜索公司人员目录，结果显示姓名、工号、部门等信息。无匹配时提示调整关键词。
2. 单选新邀请人后点击【确认】回填。取消或关闭选择页时保留打开前的已选人员。
3. 交接确认时展示原邀请人、新邀请人。
4. 提交前复核供应商归属、已审批、未拉黑，以及新邀请人已选择且与原邀请人不同。不符合时指出供应商及原因，保留选择供调整。

**办理结果**

| 结果 | 处理 |
| --- | --- |
| 交接成功 | 直接更新邀请人，免审批，供应商保持【已审批】 |
| 列表归属变化 | 新邀请人在我的邀请中查看，原邀请人的我的邀请移除该记录 |
| 交接记录 | 保存发起人、供应商、原邀请人、新邀请人、操作时间及结果 |
| 批量提交成功 | 所选记录全部更新邀请人，返回整批成功结果 |
| 批量提交失败 | 任一记录不存在、已拉黑或状态不符合条件时，整批失败，所有记录的邀请人均保持原值 |

批量失败后，用户调整选择并重新提交整批；可移除不符合条件的记录，再提交剩余记录。

### 4.8 我的评分

#### 4.8.1 查询与操作

| 查询条件 | 填写方式与规则 |
| --- | --- |
| 搜索关键词 | 按供应商名称或合作事项模糊匹配 |
| 合作类型 | 单选：技术服务、电子产品 |
| 评分时间 | 开始日期、结束日期同行，包含对应自然日。结束日期早于开始日期时，在结束日期提示“结束日期不能早于开始日期”并保留本次输入 |

我的评分卡片展示下表字段。未评分记录及历史缺失的时间、分值显示“—”。

| 字段 | 说明 |
| --- | --- |
| 供应商名称 | 本次合作关联的供应商 |
| 合作类型 | 技术服务、电子产品 |
| 合作事项 | 与填写页为同一字段，展示本次合作事项 |
| 合作时间 | 展示本次保存的合作时间；普通新增评分无自动赋值，合同待办评分初始取合同归档日期，缺值显示“—” |
| 评分时间 | 新增或修改评分提交成功的操作时间 |
| 评价得分 | 本次合作的单次得分，见4.8.2 |

| 入口 | 办理规则 |
| --- | --- |
| 供应商查询或供应商详情【评分】 | 关联当前供应商，新建一次合作评分 |
| 我的评分【评分】 | 带入该条未评分合作，完成后更新同一记录为已评分 |
| 我的评分【评分详情】 | 查看该次合作、各项评分、评价、得分和评分时间。每项按保存的分值展示只读星级和分数，支持半星。分项缺值时显示“—” |
| 我的评分【修改评分】 | 回填本人已评分记录，提交后更新原记录，保留原合作关联 |

#### 4.8.2 填写评分

| 评分字段 | 必填 | 填写或显示规则 |

我的评分与供应商详情的【合作信息及评分】展示同一评分结果。供应商评分取该供应商所有大于 0 的单次得分的算术平均值，四舍五入保留两位小数。

### 4.11 差旅账单上传

差旅账单录入向有差旅权限的供应商开放，访问和上传权限由差旅系统控制。

页面展示火车账单、酒店账单、飞机账单、租车账单四个上传入口，分别提交给差旅系统对应业务。

每次在当前页选择并上传 1 份账单文件，供应商端支持选择任意格式和大小的文件，无须填写账期。

上传期间当前类型显示处理中并暂停再次上传。差旅系统确认接收后显示成功；返回失败时展示原因并允许重试。等待超过 180 秒显示上传超时，处理结果以差旅系统回执为准。

页面提供一个【模板下载】入口，点击下载统一的 `账单上传模板.rar`。

### 4.12 审批记录与结果

注册或变更提交成功后生成审批记录，申请人从供应商详情查看进度、结果和意见。注册审批流程最终通过或驳回后，向供应商邀请人发送结果邮件，驳回邮件展示审批意见中的驳回原因。变更审批通过后，详情显示更新后的正式资料。

资料、银行或权限变更审批驳回后，本次申请结束，原申请及审批记录保留用于查看。再次办理时，从原来的【修改全部信息】【修改银行】或【分配权限】入口发起并提交一份新申请；被驳回的申请及其资料保持只读。

| 审批记录区域 | 展示及交互 |
| --- | --- |
| 当前审批进度 | 取最新审批单，展示审批类型、审批单号。节点按流程顺序纵向展示，逐项显示节点名称、审批状态、处理时间、审批人姓名及工号、代理人、审批意见。无节点时显示“暂无审批节点” |
| 审批历史 | 按审批单号分组展示以往审批，显示审批类型、单号及结果。展开查看发起时间、发起人姓名及工号。对应审批单号可进入有权查看的审批记录 |
