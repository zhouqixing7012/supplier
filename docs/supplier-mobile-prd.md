# 供应商移动端 PRD

## 1. 使用范围

内部员工可在移动端办理供应商业务，外部供应商可完成入驻及后续协同。

| 使用端 | 本次范围 |
| --- | --- |
| 供应商管理平台 | 供应商查询、我的邀请、邀请注册、代注册、供应商详情、审批记录查看、修改全部信息、修改银行、分配权限、变更邀请人、导出、我的评分 |
| 供应商协同门户 | 受邀账号注册及资料登记、登录与账户维护、供应商信息管理、采购报价、价税拆分、差旅账单上传 |

采购报价和价税拆分任务来自采购系统，上传的差旅账单由差旅系统处理。PC 专属页面改造、财务 OU 分配、黑名单办理、撰稿人新增授权、审批结束服务号通知以及审批任务中心改造在本次范围之外。注册审批首个业务节点的填写要求见 4.13。移动端管理平台将【供应商查询】【我的邀请】【我的评分】三个菜单在同一行直接展示，点击切换。

## 2. 数据权限

| 角色 | 可查看的数据范围 | 可办理操作及限制 |
| --- | --- | --- |
| 有供应商管理权限的正编员工 | 供应商查询中的普通供应商，以及获授权查看的个人撰稿人 | 邀请注册、代注册、评分、修改银行、分配权限、变更邀请人 |
| 供应商邀请人 | 当前归属本人的邀请注册及代注册记录 | 继续草稿、重新邀请、删除、交接邀请人及修改全部信息，各操作条件见对应功能 |
| 评分人 | 我的评分显示本人待办及已办的评分记录 | 填写本人未评分记录，查看本人已评分记录，修改本人具有修改权限的已评分记录 |
| 管理员、内审 | 具备导出权限的供应商记录 | 按已应用筛选条件导出。删除按相应删除权限办理，角色范围见第5章Q02 |
| 受邀供应商 | 有效邀请链接对应的供应商 | 创建账号并登记该供应商资料 |
| 协同门户供应商 | 本账号绑定的供应商资料及采购业务任务 | 办理本人资料变更、修改密码和注册邮箱、处理报价及价税拆分。有差旅系统授予的差旅权限时可上传差旅账单。工作台面向已审批、变更中的供应商 |

供应商列表及普通详情中的个人证件号保留前两位和后两位，中间用星号显示。证件原值仅用于授权业务，审批中按审批权限查看。银行账户和开户证明的查看权限与所属供应商一致。导出个人证件号码按 4.8 脱敏。

记录及附件按数据权限开放。提交前复核记录状态、归属和权限。条件变化导致无法提交时，提示涉及的记录和原因，保留已填写内容。

## 3. 通用规则

### 3.1 供应商状态与资料版本

| 状态 | 进入条件 | 可继续办理事项 |
| --- | --- | --- |
| 草稿 | 代注册资料已保存，尚未提交 | 在原记录继续填写，符合条件时删除、重新邀请或转为邀请注册 |
| 邀请中 | 邀请已发送，受邀人尚未完成账号注册 | 受邀人通过有效链接注册账号，邀请人可重新邀请 |
| 注册中 | 受邀人已创建账号，资料尚未正式提交 | 继续登记并提交注册资料 |
| 审批中 | 注册资料提交成功 | 查看审批进度，审批完成后更新注册结果 |
| 已审批 | 注册审批通过，或已生效供应商本次变更审批结束 | 按数据、状态及业务权限办理评分、资料维护、交接等操作 |
| 注册驳回 | 注册申请被驳回 | 查看审批意见，符合条件时删除 |
| 变更中 | 供应商资料、银行账户或权限变更已提交审批 | 查看本次审批。已生效资料继续供查询和下游使用，待审批资料在对应办理记录中查看 |

注册审批通过后生成或更新正式供应商资料。变更审批通过后更新正式资料；驳回时保留原正式资料和本次审批记录。审批中、变更中须等待当前审批结束后再维护资料。评分和变更邀请人的条件分别见 4.9、4.7。

### 3.2 查询、选择和提交

1. 多个已应用的筛选条件同时生效。应用后更新结果数；取消筛选保留上次已应用条件。重置清空本次筛选填写，应用后刷新查询。清空搜索词保留已应用筛选。返回来源列表恢复查询、筛选和浏览位置。
2. 业务页签点击切换。常用单选点选后回填并关闭，已选值在重开时回显。供应商状态、行业、银行及分行等需要检索的选择保留搜索。人员选择点选后点击【确认】，取消保留原值。
3. 查询中显示加载状态。空结果提示调整条件，查询失败保留条件并允许重试。批量选择仅作用于当前查询结果中可选记录，查询范围变化后重新选择。
4. 单条保存校验当前明细，下一步校验当前步骤，提交校验整份资料。校验失败时定位出错字段、明细或步骤，保留其他输入。同一次提交只生成一笔业务结果；提交失败提示原因并保留本次资料。

## 4. 功能说明

### 4.1 供应商查询、我的邀请与供应商详情

| 查询条件 | 交互与取值 | 匹配规则 |

| 供应商推荐 | 可搜索单选下拉：信息传输、计算机服务和软件业；农林牧渔业 | 按所选推荐分类查询 |
| 邀请人 | 文本输入 | 按当前邀请人姓名模糊匹配，可与搜索关键词同时使用 |

搜索关键词在两个列表中的区别已在表内列明；其余五项条件分别在哪个列表提供，见第5章Q01。

### 4.2 邀请注册与重新邀请

#### 4.2.1 填写邀请信息

| 字段 | 必填 | 交互与规则 |
| --- | --- | --- |
| 供应商类型 | 是 | 单选，决定受邀注册的资料类型 |
| 供应商名称或姓名 | 是 | 文本，个人类型填写姓名 |
| 联系人姓名 | 是 | 文本，填写接收邀请的联系人 |
| 联系人邮箱 | 是 | 邮箱格式，用于接收注册链接 |
| 联系人手机 | 是 | 国外供应商填写联系电话，内容不得含空白；其他类型按手机号格式校验 |

个人供应商按姓名填写邀请信息，同名个人可分别受邀。个人供应商重新邀请时，从【我的邀请】选中原记录办理，以供应商编码识别该记录。

所有类型提交前校验必填字段和填写格式。非个人供应商名称去除首尾空格后，匹配本人名下处于【邀请中】或【草稿】的同名记录。匹配成功时提示“您名下存在同名且为邀请中或草稿的供应商，是否重新进行邀请。”点击【重新邀请】按下述规则更新匹配记录；点击【取消】保留本次填写。通过【我的邀请】直接发起重新邀请时进入同一邀请表单。

#### 4.2.2 重新邀请与代注册转邀请

办理记录须处于【草稿】或【邀请中】。提交前复核原记录状态、归属、名称及供应商类型。

| 原注册方式 | 办理成功后的记录关系 |
| --- | --- |
| 邀请注册 | 保留原供应商记录及供应商编码，重新发送邀请 |
| 代注册 | 删除原代注册记录，生成新的邀请记录；新记录进入【邀请中】 |

原邀请注册记录重新邀请成功后，按下表更新：

| 处理对象 | 成功结果 |
| --- | --- |
| 登记资料 | 清除原资料、附件及已创建账号 |
| 邀请联系人、邀请人 | 按本次邀请更新 |
| 邀请单及链接 | 生成新邀请单号和新链接，旧链接失效 |
| 供应商状态 | 更新为【邀请中】 |
| 邀请时间 | 仍取该供应商记录创建时间 |
| 受邀人后续操作 | 通过新链接重新注册账号并登记资料 |

发送失败时保留本次填写和原记录。代注册转邀请的新建失败处理、旧资料清除时点及发送失败时完整恢复范围，见第5章Q07a、Q07b。

示例：一条原邀请注册记录重新邀请成功后，供应商编码保持不变，邀请单号和链接更新；一条代注册记录转邀请成功后，形成新的邀请记录。

#### 4.2.3 受邀人注册账号

新邀请及重新邀请的链接有效期均为 7 天。发送成功后，邀请人可在我的邀请查看【邀请中】记录；链接过期时提示联系邀请人重新邀请。

受邀人通过邮件链接注册账号，页面带入供应商名称。账号、密码、确认密码、图形验证码必填。账号须唯一；密码为 8–20 位，同时包含数字、大写字母、小写字母，两次填写一致。更换图形验证码后重新填写。

账号创建成功后，供应商进入【注册中】，继续按 4.3 登记资料。

### 4.3 代注册与受邀资料登记

**入口与步骤**

| 发起方式 | 类型及名称 | 保存与继续 |
| --- | --- | --- |
| 员工代注册 | 选择供应商类型，填写供应商名称或姓名 | 可保存草稿，从我的邀请继续原记录 |
| 受邀供应商登记 | 类型由邀请确定，名称或姓名只读 | 创建账号后继续登记资料 |

| 供应商类型 | 填写顺序 |
| --- | --- |
| 个人供应商 | 基本信息 → 银行信息 → 预览，共三步 |
| 企业、政府机构或社团、国外供应商 | 基本信息 → 联系人信息 → 银行信息 → 预览，共四步 |

**填写与切换**

【下一步】显示当前步骤序号及总步数，点击后校验当前步骤；【上一步】保留本次填写。字段及明细要求见4.3.1～4.3.4。草稿保存的必填及格式校验范围见第5章Q08。

**预览与提交**

预览展示本次提交的全部资料及附件，可返回相应步骤修正。代注册点击【提交】，受邀登记点击【提交注册】；整份资料校验通过后进入【审批中】。校验失败定位出错字段、明细或步骤并保留输入，注册审批见4.13。

#### 4.3.1 基本信息

| 字段 | 适用类型 | 必填 | 交互与规则 |
| --- | --- | --- | --- |

| 营业执照 | 企业 | 是 | 上传 1 份，大小不超过 50 MB，支持 PDF、PNG、JPG、GIF、JPC、BMP。上传后识别企业名称、统一社会信用代码等证照信息，识别后可核对修正；识别失败可手工补齐 |
