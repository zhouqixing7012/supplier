# 供应商移动端 PRD

## 1. 背景

内部员工可在移动端办理供应商业务，外部供应商可完成入驻及后续协同。

| 使用端 | 本次范围 |
| --- | --- |
| 供应商管理平台 | 供应商查询、我的邀请、邀请注册、代注册、供应商详情、审批记录查看、修改全部信息、修改银行、分配权限、变更邀请人、导出、我的评分 |
| 供应商协同门户 | 受邀账号注册及资料登记、登录与账户维护、供应商信息管理、采购报价、价税拆分、差旅账单上传 |

采购报价和价税拆分任务来自采购系统，上传的差旅账单由差旅系统处理。PC 专属页面改造、财务 OU 分配、黑名单办理、撰稿人新增授权、审批结束服务号通知以及审批任务中心改造在本次范围之外。移动端管理平台菜单提供【供应商查询】【我的邀请】【我的评分】。

## 2. 权限

| 角色 | 可查看的数据范围 | 可办理操作及限制 |
| --- | --- | --- |
| 有供应商管理权限的正编员工 | 供应商查询中的普通供应商，以及获授权查看的个人撰稿人 | 邀请注册、代注册、评分、修改银行、分配权限、变更邀请人 |
| 供应商邀请人 | 当前归属本人的邀请注册及代注册记录 | 继续草稿、重新邀请、删除、交接邀请人及修改全部信息，操作条件见 4.1 |
| 评分人 | 我的评分显示本人待办及已办的评分记录 | 填写本人未评分记录，查看本人已评分记录，修改本人具有修改权限的已评分记录 |
| 管理员、内审 | 具备导出权限的供应商记录 | 按已应用筛选条件导出。供应商查询的删除由具备对应删除权限的管理员办理 |
| 受邀供应商 | 有效邀请链接对应的供应商 | 创建账号并登记该供应商资料 |
| 协同门户供应商 | 本账号绑定的供应商资料及采购业务任务 | 办理本人资料变更、修改密码和注册邮箱、处理报价及价税拆分。有差旅系统授予的差旅权限时可上传差旅账单。工作台面向已审批、变更中的供应商 |

供应商列表及普通详情中的个人证件号保留前两位和后两位，中间用星号显示。证件原值仅用于授权业务，审批中按审批权限查看。银行账户及证明附件随对应供应商资料授权。导出个人证件号码按 4.8 脱敏。

记录及附件按数据权限开放。提交前复核记录状态、归属和权限。条件变化导致无法提交时，提示涉及的记录和原因，保留已填写内容。

## 3. 通用规则

### 3.1 供应商状态与资料版本

| 状态 | 进入条件 | 可继续办理事项 |
| --- | --- | --- |
| 草稿 | 代注册资料已保存，尚未提交 | 在原记录继续填写，符合条件时删除、重新邀请或转为邀请注册 |
| 邀请中 | 邀请已发送，受邀人尚未完成账号注册 | 受邀人通过有效链接注册账号，邀请人可重新邀请 |
| 注册中 | 受邀人已创建账号，资料尚未正式提交 | 继续登记并提交注册资料 |
| 审批中 | 注册资料提交成功 | 查看审批进度，审批完成后更新注册结果 |
| 已审批 | 注册审批通过，或已生效供应商本次变更审批结束 | 按数据、状态及业务权限办理评分、资料维护、交接等操作 |
| 注册驳回 | 注册申请被驳回 | 查看审批意见，符合条件时删除 |
| 变更中 | 供应商资料、银行账户或权限变更已提交审批 | 查看本次审批。已生效资料继续供查询和下游使用，待审批资料在对应办理记录中查看 |

草稿、账户单条保存、整份提交与审批生效分别记录。注册审批通过后生成或更新正式供应商资料。变更通过后，按审批内容更新已生效版本。驳回保留原已生效版本和本次审批记录。处于审批中或变更中时，资料维护须等待当前审批结束。评分、邀请人交接分别按各自的状态规则办理。

### 3.2 查询、选择和提交

1. 多个已应用的筛选条件同时生效。应用后更新结果数；取消筛选保留上次已应用条件。重置清空本次筛选填写，应用后刷新查询。清空搜索词保留已应用筛选。返回来源列表恢复查询、筛选和浏览位置。
2. 业务页签点击切换。常用单选点选后回填并关闭，已选值在重开时回显。供应商状态、行业、银行及分行等需要检索的选择保留搜索。人员选择点选后点击【确认】，取消保留原值。
3. 查询中显示加载状态。空结果提示调整条件，查询失败保留条件并允许重试。批量选择仅作用于当前查询结果中可选记录，查询范围变化后重新选择。
4. 同一次正式提交只生成一笔业务结果。提交失败时提示原因，保留已填写资料及已保存明细。

## 4. 页面字段及交互

### 4.1 供应商查询、我的邀请与供应商详情

| 查询条件 | 交互方式 | 枚举值或格式 | 查询规则 |
| --- | --- | --- | --- |
| 搜索关键词 | 文本输入 | 供应商名称、邀请人姓名 | 供应商查询按名称或当前邀请人姓名模糊匹配，任一命中即展示同一记录一次；我的邀请按供应商名称模糊匹配 |
| 供应商类型 | 单选下拉 | 企业供应商、个人供应商、政府机构或社团、国外供应商 | 按所选类型筛选 |
| 供应商状态 | 可搜索单选下拉 | 草稿、邀请中、注册中、审批中、已审批、注册驳回、变更中 | 按当前状态筛选 |
| 邀请时间 | 日期区间 | 开始日期、结束日期 | 可单填一端，包含对应自然日；开始日期晚于结束日期时保留条件并提示修正 |
| 供应商推荐 | 可搜索单选下拉 | 信息传输、计算机服务和软件业；农林牧渔业 | 按所选推荐分类查询 |
| 邀请人 | 文本输入 | 当前邀请人姓名 | 按姓名模糊匹配，可与搜索关键词同时使用 |

邀请时间取供应商记录创建时间，用于展示、排序、查询和导出。默认由近到远显示可访问记录。供应商查询的结果显示供应商名称、类型、审批状态、邀请人、邀请时间、更新时间、评分。我的邀请结果显示供应商名称、类型、审批状态、证件号码、联系人姓名、邮箱、电话、邀请时间、更新时间。打开名称查看详情；审批中的记录可查看审批进度。

| 操作 | 展示及办理条件 | 点击结果 |
| --- | --- | --- |
| 邀请注册、代注册 | 具有对应发起权限 | 分别进入 4.2、4.3 |
| 修改草稿 | 具备该草稿的修改权限，状态为草稿 | 回填已保存的资料、联系人和银行账户，继续原记录 |
| 重新邀请 | 我的邀请，记录为邀请中或草稿 | 进入邀请表单，按 4.2 重新发送 |
| 删除 | 具备相应删除权限。我的邀请可删草稿、注册驳回、邀请中、注册中；供应商查询可删草稿、注册驳回 | 删除前确认。成功后所选供应商资料作废，列表移除相应记录 |
| 修改全部信息 | 我的邀请，本人名下已审批且未拉黑，具有修改权限 | 进入 4.4 |
| 修改银行、分配权限 | 已审批且未拉黑，具备对应权限 | 直接进入该供应商独立维护页面，见 4.5、4.6 |
| 变更邀请人 | 已审批且未拉黑，具有交接权限 | 进入单条交接。我的邀请另提供批量变更邀请人 |
| 评分 | 变更中或已审批，具有评分权限 | 打开当前供应商评分表单 |
| 导出 | 具有导出权限 | 打开导出确认，见 4.8 |

详情页按供应商显示注册信息、基本信息、联系人信息、银行信息、分配权限、财务 OU、黑名单操作记录、审批记录、合作信息及评分。注册信息含供应商名称、类型、状态、邀请人、邀请时间、更新时间、注册方式及注册邮箱。存在名称变更时显示现用名称和曾用名。历史手工导入记录的注册方式为【历史供应商】。联系人、账户及权限分别展示各自生效的明细。合作信息及评分展示该供应商各次合作及评分结果，满足评分条件时可发起评分。

| 审批记录区域 | 展示及交互 |
| --- | --- |
| 当前审批进度 | 取最新审批单，展示审批类型、审批单号。节点按流程顺序纵向展示，逐项显示节点名称、审批状态、处理时间、审批人姓名及工号、代理人、审批意见。无节点时显示“暂无审批节点” |
| 审批历史 | 按审批单号分组展示以往审批，显示审批类型、单号及结果。展开查看发起时间、发起人姓名及工号。对应审批单号可进入有权查看的审批记录 |

单条删除【邀请中】记录后，原邀请链接失效。单条删除【注册中】或【注册驳回】记录后，原邀请链接及账号失效。打开已失效链接时，提示“该地址已失效，请联系邀请人重新邀请！”。批量删除的关联处理及会话失效口径见 6.2。

### 4.2 邀请注册与重新邀请

| 字段 | 必填 | 交互与规则 |
| --- | --- | --- |
| 供应商类型 | 是 | 单选，决定受邀注册的资料类型 |
| 供应商名称或姓名 | 是 | 文本，个人类型填写姓名 |
| 联系人姓名 | 是 | 文本，填写接收邀请的联系人 |
| 联系人邮箱 | 是 | 邮箱格式，用于接收注册链接 |
| 联系人手机 | 是 | 按手机号格式校验 |

个人供应商按姓名填写邀请信息，同名个人可分别受邀。个人供应商重新邀请时，从【我的邀请】选中原记录办理，以供应商编码识别该记录。

非个人供应商【提交】前校验表单。名称去除首尾空格后，匹配本人名下处于【邀请中】或【草稿】的同名记录。匹配成功时提示“您名下存在同名且为邀请中或草稿的供应商，是否重新进行邀请。”点击【取消】保留本次填写。通过【我的邀请】直接发起重新邀请时进入同一邀请表单。

| 操作 | 处理规则 |
| --- | --- |
| 重新邀请 | 提交时复核原记录的状态、归属、名称及供应商类型。成功后保留原供应商记录和供应商编码，清除原登记资料、附件及已创建的账号，按本次邀请更新联系人和邀请人，生成新邀请单号和新链接。受邀人打开新链接后重新注册账号并登记资料。旧链接失效，供应商状态变为【邀请中】。新链接有效期为 7 天，列表和导出的邀请时间仍取原记录创建时间。发送失败时保留本次填写和原记录 |
| 代注册转邀请注册 | 提交转换时，先删除原代注册记录，再新建邀请注册记录并发送邀请。新记录进入【邀请中】 |

新邀请成功后进入【邀请中】，可在我的邀请查看。受邀人通过邮件链接进入账号注册，链接有效期为 7 天；过期提示联系邀请人重新发起。账号注册带入邀请中的供应商名称。账号、密码、确认密码、图形验证码必填。账号验重；密码为 8–20 位，须同时包含数字、大写字母、小写字母；两次密码一致。更换图形验证码后重新填写。账号创建成功后，原供应商记录进入【注册中】，受邀人继续填写资料并提交注册。

### 4.3 代注册与受邀资料登记

代注册由员工发起，选择供应商类型后展示对应字段及步骤，可保存草稿并在我的邀请继续填写。受邀登记依据邀请确定供应商类型和名称，名称或姓名只读。个人供应商依次填写基本信息、银行信息、预览，共三步。其他类型在基本信息和银行信息之间增加联系人信息，共四步。【下一步】显示当前步骤序号及总步数，点击后校验当前步骤。点击【上一步】保留本次填写。预览显示本次提交的全部资料及附件，可返回相应步骤修正。代注册点击【提交】，受邀登记点击【提交注册】，通过整份资料校验后进入【审批中】。

#### 4.3.2 联系人信息

企业、政府机构或社团、国外供应商可添加、编辑和删除联系人。单条保存后回到当前联系人列表，删除须确认。读取已有联系人时保留其历史字段，正式提交时提示补齐必填资料。

| 字段 | 必填 | 填写规则 |
| --- | --- | --- |
| 姓名 | 是 | 文本 |
| 电话 | 是 | 文本，保留联系方式原值 |
| 邮箱 | 是 | 校验邮箱格式 |
| 部门 | 否 | 最多 50 字 |
| 职位 | 否 | 最多 50 字 |
| 微信 | 否 | 文本 |
| 备注 | 否 | 最多 400 字 |

#### 4.3.3 银行信息

银行信息支持添加、修改、删除及单条【保存此账户】。账户名称默认带入供应商名称，可修改。企业按基本账户、一般账户办理，基本账户的保存和提交条件见第 5 章。

| 字段 | 必填 | 填写或回填规则 |

### 4.10 协同门户登录、工作台及账户

| 有效期 | 选择具体截止日期时，截止日期须大于或等于成立日期或证件有效起始日期；长期按长期有效处理 | 提示“证件有效截止日期不能早于起始日期”，重新选择 |

| 企业基本账户 | 保存时拦截第二个基本账户；注册及银行变更提交时校验恰好一个有效基本账户；删除企业基本账户时拦截 | 分别提示“基本账户只能有一个”“企业供应商必须有且只有一个基本账户”“企业供应商基本账户不可删除” |
| 权限明细 | 单条保存时，所属权限及对应权限分类均须填写 | 提示“请选择所属权限和权限分类”，返回该条继续填写 |
| 变更邀请人 | 提交前复核各记录已审批、未拉黑、新邀请人已选且与原邀请人不同 | 提示具体供应商及原因，可调整记录或新邀请人 |
| 导出 | 邀请起止必填、起止顺序有效且符合条件的结果至少一条 | 提示缺少日期、日期顺序或无符合条件记录，调整后再导出 |
| 评分 | 合作类型、事项及分项分值完整；新增评分时供应商处于变更中或已审批 | 分别提示选择合作类型、填写合作事项、完成全部评分项，或“当前供应商状态不支持评分” |
| 邮箱修改 | 新邮箱格式有效，供应商自助修改时新旧邮箱不同；验证码对应当前邮箱和办理步骤 | 未获取、未填写、错误、过期分别提示；过期需重新获取，失败期间原邮箱有效 |
| 报价、价税提交 | 各真实明细的必填金额和税率有效；报价须在截止前提交 | 定位具体明细。价税修改税率时，计算前须有有效含税单价及含税金额；输入不完整时提示修正 |
| 注册业务审批资料 | 在需要分配业务、选择付款公司的审批节点提交时分别校验 | 分别提示“请至少添加一条分配业务记录”“请选择付款公司”；明细不完整时指出所在记录及缺失字段 |

## 6. 后续操作、业务结果及补充说明

### 6.1 审批结果查询

注册或变更提交成功后生成审批记录。申请人可在供应商详情查看本次审批进度、结果及意见。变更通过后，供应商详情显示更新后的正式资料。
