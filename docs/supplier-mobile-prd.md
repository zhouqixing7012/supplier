# 供应商移动端 PRD

## 1. 使用范围

内部员工可在移动端办理供应商业务，外部供应商可完成入驻及后续协同。

| 使用端 | 本次范围 |
| --- | --- |
| 供应商管理平台 | 供应商查询、我的邀请、邀请注册、代注册、供应商详情、审批记录查看、修改全部信息、修改银行、分配权限、变更邀请人、导出、我的评分 |
| 供应商协同门户 | 受邀账号注册及资料登记、登录与账户维护、供应商信息管理、采购报价、价税拆分、差旅账单上传 |

采购报价和价税拆分任务来自采购系统，上传的差旅账单由差旅系统处理。PC 专属页面改造、财务 OU 分配、黑名单办理、撰稿人新增授权、审批结束服务号通知以及审批任务中心改造在本次范围之外。注册审批首个业务节点的填写要求见 4.13。移动端管理平台将【供应商查询】【我的邀请】【我的评分】三个菜单在同一行直接展示，点击切换。

## 2. 数据权限

| 角色 | 可查看的数据范围 | 可办理操作及限制 |
| --- | --- | --- |
| 有供应商管理权限的正编员工 | 供应商查询中的普通供应商，以及获授权查看的个人撰稿人 | 邀请注册、代注册、评分、修改银行、分配权限、变更邀请人 |
| 供应商邀请人 | 当前归属本人的邀请注册及代注册记录 | 继续草稿、重新邀请、删除、交接邀请人及修改全部信息，各操作条件见对应功能 |
| 评分人 | 我的评分显示本人待办及已办的评分记录 | 填写本人未评分记录，查看本人已评分记录，修改本人具有修改权限的已评分记录 |
| 管理员、内审 | 具备导出权限的供应商记录 | 两个列表的导出权限见4.8；供应商查询的删除权限见4.1.2 |
| 受邀供应商 | 有效邀请链接对应的供应商 | 创建账号并登记该供应商资料 |
| 协同门户供应商 | 本账号绑定的供应商资料及采购业务任务 | 办理本人资料变更、修改密码和注册邮箱、处理报价及价税拆分。有差旅系统授予的差旅权限时可上传差旅账单。工作台面向已审批、变更中的供应商 |

供应商列表及普通详情中的个人证件号保留前两位和后两位，中间用星号显示。证件原值仅用于授权业务，审批中按审批权限查看。银行账户和开户证明的查看权限与所属供应商一致。导出个人证件号码按 4.8 脱敏。

供应商列表及详情字段缺值时统一显示“—”。

记录及附件按数据权限开放。提交前复核记录状态、归属和权限。条件变化导致无法提交时，提示涉及的记录和原因，保留已填写内容。

## 3. 通用规则

### 3.1 供应商状态与资料版本

| 状态 | 进入条件 | 可继续办理事项 |
| --- | --- | --- |
| 草稿 | 代注册资料已保存，尚未提交 | 在原记录继续填写，符合条件时删除、重新邀请或转为邀请注册 |
| 邀请中 | 邀请已发送，受邀人尚未完成账号注册 | 受邀人通过有效链接注册账号，邀请人可重新邀请 |
| 注册中 | 受邀人已创建账号，资料尚未正式提交 | 继续登记并提交注册资料 |
| 审批中 | 注册资料提交成功 | 查看审批进度，审批完成后更新注册结果 |
| 已审批 | 注册审批通过，或已生效供应商本次变更审批结束 | 按数据、状态及业务权限办理评分、资料维护、交接等操作 |
| 注册驳回 | 注册申请被驳回 | 协同门户登录后进入修改全部信息页；可查看审批意见，符合条件时删除 |
| 变更中 | 供应商资料、银行账户或权限变更已提交审批 | 查看本次审批。已生效资料继续供查询和下游使用，待审批资料在对应办理记录中查看 |

注册审批通过后生成或更新正式供应商资料。变更审批通过后更新正式资料；驳回时保留原正式资料和本次审批记录。资料维护的进入条件与提交条件按对应功能分别校验；修改全部信息的提交状态校验见4.4。评分和变更邀请人的条件分别见 4.9、4.7。

### 3.2 查询、选择和提交

1. 多个已应用的筛选条件同时生效。应用后更新结果数；取消筛选保留上次已应用条件。重置清空本次筛选填写，应用后刷新查询。清空搜索词保留已应用筛选。返回来源列表恢复查询、筛选和浏览位置。
2. 业务页签点击切换。常用单选点选后回填并关闭，已选值在重开时回显。供应商状态、行业、银行及分行等需要检索的选择保留搜索。人员选择点选后点击【确认】，取消保留原值。
3. 查询中显示加载状态。空结果提示调整条件，查询失败保留条件并允许重试。批量选择仅作用于当前查询结果中可选记录，查询范围变化后重新选择。
4. 单条保存校验当前明细，下一步校验当前步骤，提交校验整份资料。校验失败时定位出错字段、明细或步骤，保留其他输入。同一次提交只生成一笔业务结果；提交失败提示原因并保留本次资料。

## 4. 功能说明

### 4.1 供应商查询、我的邀请与供应商详情

#### 4.1.1 查询与列表操作

供应商查询显示第2章授权范围内的记录；我的邀请显示当前归属本人的邀请注册及代注册记录。邀请时间取供应商记录创建时间，用于展示、排序、查询和导出，默认由近到远排列。

**查询条件**

| 查询条件 | 适用列表 | 交互与取值 | 匹配规则 |
| --- | --- | --- | --- |
| 搜索关键词 | 两个列表 | 文本输入 | 供应商查询按供应商名称或当前邀请人姓名模糊匹配，任一命中即展示同一记录一次；我的邀请按供应商名称模糊匹配 |
| 供应商类型 | 两个列表 | 单选下拉：企业供应商、个人供应商、政府机构或社团、国外供应商 | 按所选类型筛选 |
| 供应商状态 | 两个列表 | 可搜索单选下拉：草稿、邀请中、注册中、审批中、已审批、注册驳回、变更中 | 按当前状态筛选 |
| 邀请时间 | 两个列表 | 日期区间，可单填开始或结束 | 包含对应自然日；开始日期晚于结束日期时保留条件并提示修正 |
| 供应商推荐 | 供应商查询 | 可搜索单选下拉：信息传输、计算机服务和软件业；农林牧渔业 | 按所选推荐分类查询 |
| 邀请人 | 供应商查询 | 文本输入 | 按当前邀请人姓名模糊匹配，可与搜索关键词同时使用 |

**查询结果**

| 字段 | 适用列表 | 说明 |
| --- | --- | --- |
| 供应商名称 | 两个列表 | 当前供应商名称 |
| 类型 | 两个列表 | 供应商类型 |
| 审批状态 | 两个列表 | 当前供应商状态，状态含义见3.1 |
| 邀请人 | 供应商查询 | 当前邀请人 |
| 证件号码 | 我的邀请 | 个人证件号按第2章脱敏 |
| 联系人姓名 | 我的邀请 | 供应商联系人姓名 |
| 邮箱 | 我的邀请 | 供应商联系人邮箱 |
| 电话 | 我的邀请 | 供应商联系人电话 |
| 邀请时间 | 两个列表 | 供应商记录创建时间 |
| 更新时间 | 两个列表 | 供应商记录更新时间 |
| 评分 | 供应商查询 | 供应商汇总评分，计算见4.9.3 |

**列表操作**

点击【详情】查看供应商资料；审批中的记录可查看审批进度。

| 操作 | 展示及办理条件 | 点击结果 |
| --- | --- | --- |
| 邀请注册、代注册 | 具有对应发起权限 | 分别进入邀请填写或代注册，见4.2、4.3 |
| 修改草稿 | 具备该草稿的修改权限，状态为草稿 | 回填已保存资料、联系人和银行账户，继续原记录 |
| 重新邀请 | 我的邀请，记录为邀请中或草稿 | 进入邀请表单，见4.2 |
| 删除 | 供应商查询由管理员批量删除；我的邀请提供单条删除 | 可删状态、确认及结果见4.1.2 |
| 修改全部信息 | 我的邀请，本人名下已审批且未拉黑，具有修改权限 | 进入整份资料编辑，见4.4 |
| 修改银行、分配权限 | 已审批且未拉黑，具备对应权限 | 进入独立维护页，见4.5、4.6 |
| 变更邀请人 | 已审批且未拉黑，具有交接权限 | 进入单条交接；我的邀请另提供批量交接，见4.7 |
| 评分 | 变更中或已审批，具有评分权限 | 打开当前供应商评分表单，见4.9 |
| 导出 | 具有导出权限 | 打开导出确认，见4.8 |

#### 4.1.2 删除供应商

| 来源列表 | 操作权限与方式 | 可删除状态 |
| --- | --- | --- |
| 供应商查询 | 删除按钮仅管理员可见，按批量删除办理；只选一条时也按批量规则校验 | 草稿、注册驳回 |
| 我的邀请 | 对本人名下记录提供单条删除 | 草稿、邀请中、注册中、注册驳回 |

确认删除后，供应商资料作废，列表移除记录。两个入口的后续结果分别如下：

| 来源及记录状态 | 删除结果 |
| --- | --- |
| 供应商查询：草稿 | 仅作废供应商资料 |
| 供应商查询：注册驳回 | 作废供应商资料并删除供应商账号；正常完成受邀注册的记录，旧邀请链接再次打开时提示失效 |
| 我的邀请：草稿 | 作废供应商资料 |
| 我的邀请：邀请中 | 作废供应商资料，原邀请链接失效 |
| 我的邀请：注册中、注册驳回 | 作废供应商资料，原邀请链接及账号失效 |

打开失效链接时提示“该地址已失效，请联系邀请人重新邀请！”。

账号删除后，重新登录提示“用户不存在！”。已登录会话保留至原有效期结束，默认有效期从本次会话签发时起算24小时；账号删除后立即禁止变更和提交操作。

### 4.2 邀请注册与重新邀请

#### 4.2.1 填写邀请信息

| 字段 | 必填 | 交互与规则 |
| --- | --- | --- |
| 供应商类型 | 是 | 单选，决定受邀注册的资料类型 |
| 供应商名称或姓名 | 是 | 文本，个人类型填写姓名 |
| 联系人姓名 | 是 | 文本，填写接收邀请的联系人 |
| 联系人邮箱 | 是 | 邮箱格式，用于接收注册链接 |
| 联系人手机 | 是 | 国外供应商填写联系电话，内容不得含空白；其他类型按手机号格式校验 |

个人供应商按姓名填写邀请信息，同名个人可分别受邀。个人供应商重新邀请时，从【我的邀请】选中原记录办理，以供应商编码识别该记录。

所有类型提交前校验必填字段和填写格式。非个人供应商名称去除首尾空格后，匹配本人名下处于【邀请中】或【草稿】的同名记录。匹配成功时提示“您名下存在同名且为邀请中或草稿的供应商，是否重新进行邀请。”点击【重新邀请】按下述规则更新匹配记录；点击【取消】保留本次填写。通过【我的邀请】直接发起重新邀请时进入同一邀请表单。

#### 4.2.2 重新邀请与代注册转邀请

办理记录须处于【草稿】或【邀请中】。提交前复核原记录状态、归属、名称及供应商类型。

| 原注册方式 | 办理成功后的记录关系 |
| --- | --- |
| 邀请注册 | 保留原供应商记录及供应商编码，重新发送邀请 |
| 代注册 | 新邀请创建且发送任务提交成功后，原草稿作废；新记录进入【邀请中】 |

原邀请注册记录重新邀请成功后，按下表更新：

| 处理对象 | 成功结果 |
| --- | --- |
| 登记资料 | 清除原资料、附件及已创建账号 |
| 邀请联系人、邀请人 | 按本次邀请更新 |
| 邀请单及链接 | 生成新邀请单号和新链接，旧链接失效 |
| 供应商状态 | 更新为【邀请中】 |
| 邀请时间 | 仍取该供应商记录创建时间 |
| 受邀人后续操作 | 通过新链接重新注册账号并登记资料 |

原邀请注册记录重新邀请失败时，保留本次填写和原记录。

代注册转邀请先创建新邀请及链接并提交发送任务，两项均成功后才作废原草稿。此前任一步失败，保留整份原基本资料、联系人、银行、证照及资质附件、财务 OU 和业务权限，附件保持可用，供继续编辑和重试。作废原草稿时，其基本资料、联系人、银行、证照及资质附件引用、财务 OU 和业务权限一并作废。

示例：一条原邀请注册记录重新邀请成功后，供应商编码保持不变，邀请单号和链接更新；一条代注册记录转邀请成功后，形成新的邀请记录。

#### 4.2.3 受邀人注册账号

新邀请及重新邀请的链接有效期均为 7 天。发送成功后，邀请人可在我的邀请查看【邀请中】记录；链接过期时提示联系邀请人重新邀请。

受邀人通过邮件链接注册账号，页面带入供应商名称。账号、密码、确认密码、图形验证码必填。账号须唯一；密码为 8–20 位，同时包含数字、大写字母、小写字母，两次填写一致。更换图形验证码后重新填写。

账号创建成功后，供应商进入【注册中】，继续按 4.3 登记资料。

### 4.3 代注册与受邀资料登记

**入口与步骤**

| 发起方式 | 类型及名称 | 保存与继续 |
| --- | --- | --- |
| 员工代注册 | 选择供应商类型，填写供应商名称或姓名 | 点击【下一步】校验并保存当前步骤，从我的邀请继续原草稿 |
| 受邀供应商登记 | 类型由邀请确定，名称或姓名只读 | 创建账号后继续登记资料 |

| 供应商类型 | 填写顺序 |
| --- | --- |
| 个人供应商 | 基本信息 → 银行信息 → 预览，共三步 |
| 企业、政府机构或社团、国外供应商 | 基本信息 → 联系人信息 → 银行信息 → 预览，共四步 |

**填写与切换**

【下一步】显示当前步骤序号及总步数，点击后校验当前步骤；【上一步】保留本次填写。字段及明细要求见4.3.1～4.3.4。员工代注册通过【下一步】分步保存：基本信息和适用证照须通过当前步必填、格式、日期及查重校验后保存为草稿；联系人、银行在各自步骤校验并保存。校验失败保留输入，停留当前步骤。后续步骤更新同一草稿。

**预览与提交**

预览展示本次提交的全部资料及附件，可返回相应步骤修正。代注册点击【提交】，受邀登记点击【提交注册】；整份资料校验通过后进入【审批中】。校验失败定位出错字段、明细或步骤并保留输入，注册审批见4.13。

#### 4.3.3 银行信息

银行信息支持添加、修改、删除及单条【保存此账户】。账户名称默认带入供应商名称，可修改。企业账户分为基本账户、一般账户。

| 字段 | 必填 | 填写或回填规则 |
| --- | --- | --- |
| 账户类型 | 企业必填 | 基本账户、一般账户；仅企业显示 |
| 开户银行 | 是 | 从银行目录搜索并选择正式银行名称；结果显示银行名称、国家或地区代码及名称 |

| 开户所在市 | 是 | 选择分行带出，只读；缺值时阻止保存 |
| 账户名称 | 是 | 最多 100 字 |
| 银行账号 | 是 | 去除账号中的空格后校验并保存，最多 50 字，按文本保存并保留前导零 |
| 币种 | 是 | 从可用币种选择 |
| 开户证明 | 是 | 支持PNG、JPG、GIF、JPC、BMP图片，每份最大50 MB；每条银行账户上传1份，可查看已保存的证明 |

单条保存须填写表中必填字段。账号去除空格后为空时提示填写银行账号，缺少开户证明时提示上传，国家或地区为空时提示选择开户银行。注册提交须至少有一条有效账户。

企业账户同时执行以下校验：

| 操作 | 校验与提示 |
| --- | --- |
| 保存账户 | 第二个基本账户不能保存，提示“基本账户只能有一个” |
| 提交注册或银行变更 | 须恰好有一个有效基本账户，否则提示“企业供应商必须有且只有一个基本账户” |
| 删除已生效基本账户 | 保留该账户，提示“企业供应商基本账户不可删除” |
| 修改或删除本次新增且尚未提交的基本账户 | 可修改，也可删除；修改后保存仍按账户字段及基本账户数量校验，删除后从本次填写中移除 |

### 4.4 修改全部信息

**进入编辑**

| 入口 | 办理条件及进入位置 | 提交成功后的返回位置 |
| --- | --- | --- |
| 管理平台“我的邀请”【修改全部信息】 | 本人名下、已审批且未拉黑，具有修改权限；带入该供应商已生效资料 | 我的邀请 |
| 协同门户“供应商信息管理”【修改】 | 从基本信息、联系人信息或银行信息进入相应编辑步骤；进入编辑与提交时的状态分别校验 | 来源供应商信息管理页面 |

个人供应商按“基本信息—银行信息—预览”共三步办理；其他类型按“基本信息—联系人信息—银行信息—预览”共四步办理。页面显示步骤条，前后切换保留本次整份资料。

已有独立银行待提交资料时，仍可进入【修改全部信息】。提交整份资料时重新校验供应商当前状态；处于【变更中】时阻止提交，提示当前状态并保留本次填写。

**填写与预览**

基本字段、联系人、银行及资质分别按4.3.1～4.3.4填写，保留对应供应商类型的适用条件。邀请人可同时修改供应商注册邮箱。修改已有供应商时，名称及证件号码按4.3.1排除自身后查重。

单条保存的联系人、银行账户及资质明细仍属于本次整份修改。【下一步】显示当前步骤并校验当前步骤；进入预览前校验整份资料，预览汇总本次拟提交内容。

**取消与提交**

| 操作或结果 | 处理 |
| --- | --- |
| 已有修改时取消或离开 | 提示“是否放弃本次全部修改？” |
| 【继续编辑】 | 保留本次全部内容 |
| 放弃修改 | 恢复进入编辑前的整份资料，包含附件、注册邮箱，以及已单条保存的新增、修改、删除 |
| 预览后提交 | 复核当前供应商状态并校验整份资料；处于【变更中】时阻止提交；成功后进入【变更中】并返回来源，可在审批记录查看进度及修改前后资料 |
| 提交失败 | 保留本次修改，提示原因 |
| 审批通过 | 更新正式资料；邀请人修改的注册邮箱同步更新至正式注册邮箱和账户验证邮箱 |
| 审批驳回 | 保留原正式资料和本次审批记录；再次办理从原申请入口发起新申请，见4.13.2 |

示例：在本次整份编辑中新增一条联系人并保存，再修改银行账户；点击【取消】并确认【放弃修改】后，两项修改均撤销，恢复进入编辑前的资料。

### 4.5 修改银行

**进入与维护账户**

供应商处于【已审批】且未拉黑，操作人具备对应权限时，从供应商查询或我的邀请进入独立维护页。页面展示供应商名称、类型及账户列表，账户字段和基本账户校验见4.3.3。

| --- | --- |

**离开与提交审批**

点击左上角返回图标离开，点击底部【提交审批】提交本次变更。已保存的待提交资料在退出或重新登录后仍可继续处理。

| 提交失败 | 保留待提交内容 |
| 审批通过 | 更新正式银行信息 |
| 审批驳回 | 保留原正式银行信息和本次审批记录；再次办理从原申请入口发起新申请，见4.13.2 |

示例：在独立“修改银行”页保存一条新账户后返回，重新登录仍可继续提交该账户；4.4整份资料编辑中的【放弃修改】则撤销本次整份修改。

| 不含税金额 | 含税金额÷（1＋税率） | 四舍五入保留两位小数 |
| 税额 | 含税金额×税率÷（1＋税率） | 四舍五入保留两位小数 |

公式中的税率按百分比换算，例如13%按0.13计算。手工调整其他字段时，同一行其他值保持不变；再次修改税率时重新计算上述三个字段。

计算前须有有效含税单价和含税金额，输入不完整时提示修正。单条【确定】校验并保存当前明细；整单【提交】将订单转交采购系统，由采购系统执行整单总额校验。采购系统处理成功后进入已处理。

### 4.12 差旅账单上传

差旅账单录入向有差旅权限的供应商开放，访问和上传权限由差旅系统控制。

页面展示火车账单、酒店账单、飞机账单、租车账单四个上传入口，分别提交给差旅系统对应业务。

每次在当前页选择并上传 1 份账单文件，供应商端支持选择任意格式和大小的文件，无须填写账期。

上传期间当前类型显示处理中并暂停再次上传。差旅系统确认接收后显示成功；返回失败时展示原因并允许重试。等待超过 180 秒显示上传超时，处理结果以差旅系统回执为准。

页面提供一个【模板下载】入口，点击下载统一的 `账单上传模板.rar`。

### 4.13 注册审批与审批结果

#### 4.13.1 注册审批首个业务节点

注册审批的第一个业务审批节点在点击【同意】时填写并校验分配业务，至少添加一条明细。后续节点办理审批。

| 字段 | 必填 | 填写规则 |
| --- | --- | --- |
| 所属权限 | 是 | 单选 |
| 权限分类 | 是 | 按所属权限选择对应分类，权限与分类关系见 4.6 |
| 付款公司 | 是 | 从付款公司选择弹窗中选择，确认后回填当前明细，取消保留原值 |

**分配业务校验与生效**

| 条件 | 提示与处理 |
| --- | --- |
| 未添加分配业务明细 | 提示“请至少添加一条分配业务记录” |
| 明细未选付款公司 | 提示“请选择付款公司”，指出对应明细 |
| 明细缺少其他必填字段 | 指出所在明细及字段 |

点击【同意】时执行上表校验；点击【驳回】时跳过分配业务必填校验，本节点已填写的分配业务明细随本次驳回丢弃。该节点提供【同意】【驳回】操作。注册审批通过后写入已分配的业务记录。

#### 4.13.2 审批进度与历史

注册或变更提交成功后生成审批记录，申请人从供应商详情查看进度、结果和意见。变更审批通过后，详情显示更新后的正式资料。

资料、银行或权限变更审批驳回后，本次申请结束，原申请及审批记录保留用于查看。再次办理时，从原来的【修改全部信息】【修改银行】或【分配权限】入口发起并提交一份新申请；被驳回的申请仅供查看，不支持编辑后重新提交。

| 审批记录区域 | 展示及交互 |
| --- | --- |
| 当前审批进度 | 取最新审批单，展示审批类型、审批单号。节点按流程顺序纵向展示，逐项显示节点名称、审批状态、处理时间、审批人姓名及工号、代理人、审批意见。无节点时显示“暂无审批节点” |
| 审批历史 | 按审批单号分组展示以往审批，显示审批类型、单号及结果。展开查看发起时间、发起人姓名及工号。对应审批单号可进入有权查看的审批记录 |
