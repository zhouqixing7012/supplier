## 需确认的业务范围

1. 撰稿人授权对象、操作范围、有效期、撤销及历史数据和移动端范围。
2. 主动变更邀请人的适用人员、批量范围、替代审批、其他节点及生效时点。原邀请人审批取消已作为本次明确需求。

4. 审批通知的现有覆盖、渠道、接收人与发送时点；MyFamily入口名称及目录。
5. 付款公司选择偏移的实际发生端、添加银行提交异常的复现及报错。
