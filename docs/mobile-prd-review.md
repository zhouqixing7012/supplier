## 当前原型额外差异

- 个人门户固定展示联系人页签，注册则跳过联系人步骤；个人门户显隐已列为待确认。
- 单条邀请人变更包含审批分流提醒，批量直接更新演示结果；审批与生效口径需统一。
- 差旅已采用最新的四类当前页上传方案，旧权限跳转结论不再适用。上传实现向适配函数传入180秒超时参数，但该层未自行执行超时控制；真实超时及结果核对仍需验证。
- 银行信息申请结果为暂存摘要，正式审批及银行目录生效尚无完整演示。
- 评分运维批量发起按钮禁用，评分保存总分为空；总分映射及批量执行仍需业务结论。
