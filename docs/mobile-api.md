接口契约见[供应商管理平台接口文档](供应商管理平台接口文档.pdf)。这一轮改造移动网页原型，页面继续使用现有操作和界面。

| 用途 | 入口 |
| --- | --- |
| 原型运行与离线导图 | `src/api/mobile/index.js` 的 `createMobileMockApi()`。每个移动原型实例创建独立会话。移动管理台和协同门户共享演示供应商正式资料与审批。双窗口审批演示只在三个指定演示供应商之间使用浏览器存储同步资料。 |

## 资料与邮箱变更演示

从移动协同门户登录页展开【查看演示账号】。图形验证码初始为 `cbvs`，登录邮箱验证码为 `123456`。账户维护的【获取验证码】在原型内回填演示码。

| 供应商 | 账号 | 初始密码 | 初始注册邮箱 | 初始场景 |
| --- | --- | --- | --- | --- |
| 协同门户演示供应商 | `supplier-demo` | `Demo1234` | `supplier@example.com` | 已审批，可新建变更 |
| 邮箱变更演示供应商 | `supplier-email` | `Email1234` | `email-review@example.com` | 已提交邮箱变更 |
| 资料变更演示供应商 | `supplier-profile` | `Profile1234` | `profile-review@example.com` | 已提交经营范围变更 |

员工在移动管理平台【我的邀请】按供应商名称搜索，打开【查看审批进度】，在「原型演示 · 审批处理」执行【模拟通过】或【模拟驳回】。切回同一原型的门户可观察邮箱和资料状态。账户修改成功后，再次登录时使用当前生效邮箱。

需演示员工填写期间供应商先修改邮箱时，点击登录页【打开双窗口审批演示】，用含 `?demo-shared=1` 的相同站点地址开两个标签。一个留在移动管理平台，一个登录协同门户。双窗口模式的演示数据可在同一浏览器内保留，普通地址重新打开时使用独立初始数据。

正式联调需在同一次事务内校验供应商状态、待审批邮箱申请和邮箱版本，并按申请的字段变更写入正式资料。邮箱版本、供应商资料邮箱和登录账号邮箱随同一次更新提交。资料变更对明细按稳定记录标识匹配。业务规则见 [移动端 PRD](supplier-mobile-prd.md#493-账户维护)。

## 演示能力

- 管理端 Mock API 维护供应商、邀请、代注册草稿、受邀登记、邀请人变更、银行及权限变更、评分和银行信息申请。页面保留输入、操作确认、返回、筛选交互和结果提示。银行暂存继续使用原有存储口径。
- 移动端与 PC 的两个供应商列表共用[数据权限规则](supplier-mobile-prd.md#22-数据权限)。移动端演示入口为 `#/mobile/query?map=1&role=employee`，PC 为 `#/admin/suppliers?role=employee`。可将角色换为 `admin_supplier`、`expLaPeople` 或 `admin`。两端的供应商查询支持在演示地址中追加 `inviterCode` 验证精确匹配。演示身份的工号为 `MOCK-CURRENT`。
- 门户 Mock API 维护演示账户、资料暂存和审批提交、报价及价税拆分的单条暂存及整单提交。差旅沿用宿主服务选项及本地演示。
- 直接打开的离线导图和历史截图状态沿用各自的演示会话。Mock 提交只产生演示结果。

## 正式接口适配

| 服务键 | 文档中的服务 | 已封装的调用 |
| --- | --- | --- |
| `center` | 供应商中心 | 供应商分页及明细、查重、邀请、注册、删除、临时变更、银行与权限、评分、导出。 |
| `approval` | 供应商审批 | 审批进度及历史。 |
| `user` | 供应商用户 | 员工权限查询。 |
| `quote` | 供应商采购服务 | 报价、价税拆分的分页、详情及整单提交。 |

公共请求处理 JSON、`ResultInfo` 结果码、业务及网络错误、取消信号和二进制导出。供应商分页按 `PageIndex` / `PageSize` 传参，长整数 ID 使用字符串。以真实接口返回的 `totalRows`、`currentPage` 和 `data` 接服务端分页。正式数据权限以网关和后端的身份为准。

HTTP 封装接收服务原始参数及 DTO。演示页面由 Mock 层提供视图状态。启用真实页面前，需确认网关如何从已认证登录身份注入或核验 `userCode`，以及分页到视图模型的映射、邀请人员工编码和行业枚举。文档未定义完整的登录、验证码、文件上传或银行信息申请契约，相关流程仍以 Mock 或已有宿主能力供演示。没有配置服务、遇到网络错误或业务失败时，HTTP 封装直接返回错误。
