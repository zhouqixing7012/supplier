## 2026-10-22｜供应商 AI 问答助手

**状态：用户提出，待细化。**

### 用户原话

> 我目前想到的一个项目是供应商的AI问答，在供应商管理平台和协同门户增加一个AI助手解答用户的疑问，因为平常供应商和员工的使用问题反馈都比较多

### 痛点和目标

供应商和员工使用问题反馈较多，拟在管理平台和协同门户增加助手，帮助用户解决疑问。讨论建议聚焦降低使用门槛、减少重复人工咨询；目标值尚未确认。

### 讨论建议（待确认）

| 方面 | 建议 |
|---|---|
| 两端服务 | 门户面向供应商，管理平台面向员工，共用知识底座并按权限提供内容 |
| 一期范围 | 操作与规则咨询、常见异常排查和转人工；业务进度查询另行评估 |
| 知识建设 | 从真实咨询记录选取20—30个高频问题，明确责任人、适用对象、来源及版本 |
| 回答 | 提供步骤、条件、来源和入口；依据不足时明确说明并转人工 |
| 人工衔接 | 携带问题上下文，明确接收人和处理结果 |
| 权限 | 业务查询由后端校验，不能只靠提示词区分用户 |
| 运营 | 统计高频、未解决、错误回答及知识缺口 |

效果评估建议：回答准确性、操作完成情况、人工咨询量、重复咨询率、转人工承接情况及权限问题。指标与目标值待定。

下一步：抽样最近一个月咨询，区分操作规则、业务进度和系统异常；确认知识来源、一期范围、人工承接渠道与基线，再形成独立功能PRD。

## 2026-10-22｜AI 信息填写与材料预检查

**状态：用户提出，价值评估中。**

### 用户原话

> 还有一个是AI信息填写，比如供应商把相关资料的文档上传后调大模型接口分析识别并将相应内容填充至我们的表单对应字段，但是这个有一个问题就是大部分专业信息都在营业执照上，目前营业执照已经用天眼查数据去做一遍核验了是不是，所以这个功能是不是有些鸡肋

### 想法与讨论建议（待确认）

上传资料后识别内容，匹配对应表单字段，由用户确认后填写。

需评估与现有工商数据服务的重叠：若基本信息已经自动带出，仅识别营业执照的增量价值可能有限；若其他材料录入或不一致问题较多，可评估开户证明、专业资质提取及材料预检查。查询补全、图片识别和真实性核验应分别核实。

下一步：确认真实系统回填范围、其他材料录入量和退回原因，再决定是否单独立项或作为AI助手扩展能力。优先级尚未确定。
