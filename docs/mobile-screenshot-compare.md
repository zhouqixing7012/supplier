# 原图对照

移动端原型右上角提供“原图对照”开关，默认关闭。开启后，桌面切换为左侧当前原型、右侧原始截图，两栏等宽、顶部对齐。关闭后恢复原型居中；窄屏使用右侧浮层，通过“关闭”返回原型。

## 图片来源

47张原始截图位于 `docs/screenshot/`。组件通过 Vite 资源导入直接打包该目录，开发与生产环境均自动显示原图。查看者无需登录 GitHub 或手动载入图片。

- 页面匹配复用 `mobile-data.js` 的47张截图索引，结合注册步骤、筛选、批量选择、银行编辑、人员选择及部分内部弹层选择图片。
- 同一页面有多个历史状态时提供候选选择；切换到其他页面或步骤后恢复自动匹配。
- 新增业务页面和没有历史截图的状态展示“暂无对应的历史截图”。
- 原图独立滚动，默认采用“与原型等宽”，并保留10%、25%、33%、50%、75%、100%、150%、200%手动缩放，切换截图时保留当前选择。
- 已查看47张原图，核对其页面及历史状态与索引一致。原图用于对照现系统，当前原型继续保留已确认的业务和交互调整。
