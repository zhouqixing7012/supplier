# 原图对照

移动端原型右上角提供“原图对照”开关，默认关闭。开启后，桌面右侧展示当前页面对应的历史截图；窄屏使用右侧浮层，可通过“关闭”返回原型。

- 复用 mobile-data.js 中的47张历史截图索引，结合当前页面、注册步骤、筛选、批量选择、银行编辑、人员选择及部分内部弹层匹配。
- 同一页面有多个历史状态时提供候选选择；切换到其他页面或步骤后恢复自动匹配。
- 新增业务页面和没有历史截图的状态展示“暂无对应的历史截图”。当前映射依据仓库原有索引，尚未重新查看全部原图作视觉复核。
- 原图独立滚动，支持100%、150%、200%缩放。

## 原图载入

当前仓库没有47张原始图片。可点击“批量载入原始截图”，选择保留原文件名的 JPG/PNG/WebP 文件。按 Screenshot_20261014_时间_com.sohu.ehr.jpg 精确识别；图片保留在当前页面会话中，刷新后需要重新载入，不上传到服务器。

后续如需所有访问者直接查看，可将获得授权的原图放入 public/mobile-assets/original-screenshots/，保留索引文件名；组件会自动读取该目录。正式原图尚未接入，本次没有把其他图片替代为原图。
