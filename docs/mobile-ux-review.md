# 移动端交互变更复查

复查范围：ef88ee6之后的b1c9609、e09a141两个提交，以及本轮用户明确的六项反馈。对照原说明书和当前实现，检查任务收益、信息可读性、取消/返回/继续编辑、权限及数据完整性；不以构建通过代替交互判断。

## 结论及处理

|变更|判断依据|处理|
|---|---|---|
|供应商蓝条、类型/状态/评分恢复展示|有助识别记录与跨记录比较，不增加操作成本|保留|
|可展开竖向注册步骤|竖向避免窄屏重叠，默认摘要保留表单首屏；个人步骤仍跳过联系人|保留，不固定展开整条流程|
|常用动作直达，权限菜单去掉中间层|减少常见任务步骤；低频动作保留在更多操作|保留|
|查询卡片更多信息折叠|查询只省两项字段，却新增逐条展开；我的邀请联系人信息也需要核对|取消折叠，原字段直接显示|
|统一选择后确认|不适合简单筛选点选；滚轮和参考目录需要提交边界|筛选点选即回填收起，筛选页统一确定；日期滚轮、银行、人员保留确认|
|超过6项自动搜索|状态7项短名称可直接扫读，键盘反而挡选项|去掉数量阈值；显式按目录查找需求配置搜索|
|供应商推荐是/否|原说明书无布尔枚举依据，用户明确按行业目录|恢复21项行业，保留当前字段名并记录来源差异；注册行业复用完整目录|
|长标签自动上下排|适合邮箱/银行长值，不适合固定长度日期|日期显式同行，320px仍保留；统一左侧对齐及有效的重置按钮样式；普通短字段和长字段按已有内容重排|
|标签目录与多选图标|两个不同任务用了相似菜单图标，普通查询多选还被条件隐藏|目录用下箭头；多选用复选列表，恢复筛选旁开关及选择计数|
|导出日期/范围页|必填条件前置、逐条选中和下载入口有价值；普通账号开放入口违背原权限|保留页面，只在有权限演示场景开放；允许在导出页调整日期而不被来源日期裁切锁死|
|评分基础信息折叠、半分操作|核心任务为评分；名称和分值优先，完整基本信息仍可查看|保留；清理评分及银行申请的重复错误提示|
|正常文档流的结果提示|不会悬浮遮挡列表和底部动作，可持续查看|保留|
|地址半屏、单条联系人/银行编辑|减少无关页面跳转，保留单条保存和整体提交的区别|保留；全国地区及字母索引仍未具备，不声称完成|
|门户首页/任务/账户导航|用户已确认，仅影响门户，不重组管理平台|保留；证照只放资料页，避免账户页重复内容；退出时明确说明未提交修改将被放弃|
|门户资料保存后前后对比|有助提交前核对，但缺少继续编辑且新分组保存可能覆盖之前修改|增加继续修改，已保存草稿作为下一次编辑基线；正式版本保持不变|
|联系人/银行按数组位置做对比|删掉第一条会把后续记录误报为修改，影响审批判断|按稳定记录ID匹配，明确新增、修改、删除；旧无ID数据仅退化为原位置|
|价税直达与去重|直达单一任务、每物料唯一字段组有价值，但标题返回错误回首页|保留，标题返回恢复任务标签；数值输入和提交继续等待PC规则|

## 选择模式与权限

恢复多选入口不等于开放批量删除。普通查询示例允许选择与退出，未提供批量动作权限时明确提示；管理员批量删除只能选择草稿，其他状态不可删除。我的邀请批量变更邀请人的业务规则仍待确认，不生成虚假的执行成功。

导出遵循原说明书内审/管理员权限。角色截图仅是原型演示入口，不是生产认证或接口权限校验。原型使用的行业标签为会话样本，不代表真实供应商数据。

## 验证范围和限制

生产构建及浏览器任务验证结果记录在 `mobile-prototype.md`。检查涵盖筛选的暂存/取消/应用、行业匹配、多选与权限、320/390px日期同行、完整列表字段、门户跨分组继续编辑、按记录身份区分删除，以及价税返回来源。

真实接口、真实设备、内嵌浏览器、软键盘、读屏、真实拍照和审批完成状态未验证。原系统偶发遮罩没有可复现材料；价税公式/精度、完整地区目录、真实导出链接及PC上线公告仍不能记为已完成。
