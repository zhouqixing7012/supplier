# PR付款按供应商名称和银行账号查询

## 一、需求背景

PR系统付款功能重构计划于2027年1月27日上线。付款环节需要按供应商名称、银行账号或两者的组合查询供应商及银行账户，供付款人员核对。

## 二、需求详情

### 查询入参

| 入参 | 检索条件 |
| --- | --- |
| 供应商名称 | 按供应商名称模糊查询 |
| 银行账号 | 按银行账号模糊查询 |
| 供应商名称&银行账户 | 同时按供应商名称和银行账号模糊查询，取两个检索结果的交集 |

查询前去除供应商名称和银行账号检索值的首尾空格，第三个入参涉及的检索值也按此处理。

### 检索规则

| 传参情况 | 返回结果 |
| --- | --- |
| 传入【供应商名称&银行账户】 | 仅按该入参取交集，返回同时匹配供应商名称和银行账号的记录。前两个入参即使同时传入，也忽略。交集为空时返回空结果。 |
| 只传入【供应商名称】 | 返回供应商名称匹配的记录。 |
| 只传入【银行账号】 | 返回银行账号匹配的记录。 |
| 同时传入【供应商名称】和【银行账号】 | 取两项检索结果的并集。符合任一条件即可返回，同一条供应商银行账户记录同时命中时只返回一次。 |

例如，供应商名称命中账户甲、乙，银行账号命中账户乙、丙。使用前两个入参查询时返回甲、乙、丙，使用第三个入参按相同条件查询时只返回乙。

### 可查询范围

- 供应商状态为【已审批】或【变更中】。
- 银行账户仅返回已审批生效的信息。银行信息变更审批期间，仍返回原已审批生效的信息。新增银行账户在审批通过并生效后进入查询结果。

### 返回字段

| 信息分类 | 字段 |
| --- | --- |
| 供应商信息 | 供应商名称、供应商VENDORID |
| 银行账户信息 | 开户行名称、分行名称、账户名称、银行账号、银行国家编码、省、市、供应商ACCOUNTID |

## 三、当前尚未定义

| 待确认事项 | 建议及影响 |
| --- | --- |
| 【供应商名称&银行账户】如何携带检索值 | 建议在一个入参中分别传递名称和账号检索值。若PR系统入口只有一个搜索框，需确认是用同一个关键词匹配两列，还是按约定拆分名称和账号。两种方式会返回不同结果。 |
| 全空、仅空格及第三个入参缺少检索值 | 建议按缺少有效查询条件返回校验结果，避免查出全量数据。需确认第三个入参为空或缺值时，是直接返回校验结果，还是按未传第三个入参处理。 |
| 按名称命中供应商，但该供应商没有已审批生效的银行账户 | 建议付款账户查询仅返回带有已审批银行账户的记录。是否单独返回供应商基本信息，需PR系统确认。 |
