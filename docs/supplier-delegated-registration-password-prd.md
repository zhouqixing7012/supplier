# 代注册自动生成初始密码规则调整 PRD

## 1. 需求背景

供应商协同门户的注册和修改密码使用相同的密码校验规则：密码长度为8–20位，且同时包含数字、大写字母和小写字母。

员工通过供应商管理平台代注册供应商时，系统会自动创建账号和密码，并将账号及初始密码发送至供应商注册邮箱。目前系统生成的初始密码为6位随机数字或字母组合，无法满足协同门户现行密码校验要求。

## 2. 需求目标

调整代注册流程自动生成的初始密码，使其符合供应商协同门户注册和修改密码使用的密码校验规则，保证供应商收到初始密码后可正常登录。

## 3. 需求规则

| 项目 | 规则 |
| --- | --- |
| 适用场景 | 员工在供应商管理平台执行代注册，系统自动创建供应商账号及初始密码 |
| 密码长度 | 8–20位，包含8位和20位 |
| 字符要求 | 至少同时包含1位数字、1位大写英文字母和1位小写英文字母 |
| 生成方式 | 系统随机生成，生成结果必须满足上述长度及字符要求 |
| 密码发送 | 账号创建成功后，继续将账号及初始密码发送至供应商注册邮箱 |

## 4. 校验与处理

1. 系统生成初始密码后，须校验密码长度及字符组成。
2. 生成结果不符合规则时，不得将该密码发送给供应商；系统重新生成，直至得到符合规则的密码。
3. 自动生成的初始密码须通过协同门户现行注册及修改密码的同一套密码规则校验。
4. 本需求只调整代注册自动生成的初始密码，不调整供应商注册页面和修改密码页面的密码校验规则。

## 5. 验收标准

| 编号 | 验收场景 | 预期结果 |
| --- | --- | --- |
| 1 | 通过代注册创建供应商账号 | 系统生成8–20位随机初始密码 |
| 2 | 检查生成密码的字符组成 | 每个密码均至少包含数字、大写英文字母和小写英文字母 |
| 3 | 使用生成的初始密码登录协同门户 | 密码符合现行密码校验规则，可正常通过密码校验 |
| 4 | 检查初始密码邮件 | 邮件中的账号及初始密码与系统创建的账号凭据一致 |
| 5 | 连续创建多个代注册账号 | 每次生成的初始密码均满足长度和字符组成要求 |
