# 移动端原型需求评审模式

此功能用于产品和前端评审，不属于供应商最终业务页面，不计入业务页面数量。

## 使用

1. 打开管理平台或协同门户移动原型，点击悬浮的“需求评审”开关。
2. 点击编号或“查看标注”查看需求详情；“定位到原型”关闭面板并定位对应位置。宽屏以红字及红色引线指向原型，窄屏点击编号使用底部详情面板。
3. 点击“新增标注”，再点击字段、按钮或有标题的卡片，填写标题和需求详情；选点不会执行原来的业务按钮。
4. 已有标注通过“编辑详情”修改。未保存关闭时提供继续编辑、放弃修改。
5. “导出”生成JSON文件；“导入”校验文件后按编号合并。当前页面不可定位的本机批注会标示“当前页面未显示”，不贴到其他记录。
6. 关闭开关恢复普通演示，不显示编号、引线或详情。

## 保存与来源

- 原型预置22类共用需求说明，来源为本次已确认决定及项目UI规范、移动端PRD和工程说明，覆盖主要改动；这不是完整PRD逐字段覆盖证明。
- 预置说明来自`mobile-review-data.js`，随版本发布。字段/按钮批注绑定当前业务场景及卡片上下文，默认不跨页面套用。
- 编辑和新增仅保存于当前浏览器的本机存储，刷新可恢复。其他浏览器需导入文件；不会自动同步到团队、GitHub或正式PRD。
- 评审批注与已确认说明区分展示；编辑预置说明后成为本机评审批注，正式业务决定仍应更新对应PRD。
- 导出包含本机批注及当前页面可定位的预置说明。导入最多500条、2MB；标题100字、详情4000字，拒绝重复编号、未知定位类型、未知组件及不支持的文件版本。导入失败不覆盖已有标注，存储失败明确报错。

## 定位与交互

- 从当前顶层业务全屏页或弹层解析目标，排除动效副本、不可见层和评审层自身。
- 位置跟随窗口及内部滚动、尺寸变化和300ms以内入场采样；受内部滚动区裁剪的目标不显示标记。
- 评审详情打开时保存底层锚点快照，保持可查看和编辑；关闭后恢复实时扫描。
- 同类资料集合已包含空态说明时，不重复增加相同位置的通用空态标记。当前页面编号按布局顺序排列。
