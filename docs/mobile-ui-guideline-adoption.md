## 明确保留与不迁入

- 保留邀请起止日期各自行内显示，不按通用资产规则合成日期区间。
- 保留列表全部已确认字段，不把资产卡片的摘要建议用于重新折叠供应商信息。
- 保留当前蓝条、可展开竖向步骤、滑动标签、独立多选开关、门户底部导航及桌面/移动样式隔离。
- 不迁入桌面三列查询/详情、32px控件、页面按钮居中和PC弹窗Footer布局。
- 不升级Ant Design或迁移移动组件库，不引入资产盘点、电子签、财务角色、统计和审批规则。
- 不按资产规则删除供应商已有代理人等审批字段；业务字段仍由供应商PRD决定。
- 原素材缺失时不生成并声称取得了同一空状态插图；本轮采用已有文案，不新增装饰插图。

## 实现与验证边界

本轮更改集中在移动公共UI、样式、供应商列表和筛选上下文；PRD仅补充已应用摘要、结果数量与选择范围规则，不增加依据章节。实际验证结果见mobile-prototype.md。

所有供应商、审批、文件及筛选结果仍为会话原型数据。真实接口、真机、软键盘、系统字体放大和内嵌浏览器不因规范更新而视为验证完成。
